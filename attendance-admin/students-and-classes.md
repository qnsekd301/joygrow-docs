# 학생과 반 관리

학생 정보는 출석, 목양, 포인트와 보고서가 함께 사용하는 기준 정보입니다. 이름·반·예배를 정확히 유지해야 다른 기록도 올바르게 연결됩니다.

## 학생을 등록할 때

1. 같은 이름의 학생이 이미 있는지 검색합니다.
2. 이름, 반, 예배와 필요한 기본 정보를 입력합니다.
3. 동명이인이면 반과 예배로 구분합니다.
4. 저장한 뒤 출석 명단에 정상적으로 보이는지 확인합니다.

## 자주 하는 관리

| 작업 | 확인할 것 |
|---|---|
| 학생 정보 수정 | 이름과 기존 기록의 연결 유지 |
| 반 이동 | 새 반과 적용 시점 확인 |
| 예배 변경 | 출석 화면에 보이는 명단 확인 |
| 학생 삭제 | 과거 출석·목양 기록에 미치는 영향 |
| 교사 배정 | 담당 반과 계정 권한이 같은지 확인 |

학생을 새로 만들기 전에 반드시 검색하세요. 동명이인은 한 사람으로 합치지 말고 반과 예배로 구분합니다. 반대로 같은 학생을 호칭이나 띄어쓰기만 바꿔 여러 번 등록하지 않습니다.

삭제가 필요하면 바로 영구 삭제하지 말고 먼저 휴지통으로 보내 복구 가능성을 남겨 둡니다.

> 학생 명단이 정확해야 출석과 목양 기록도 한 아이에게 온전히 모입니다.
