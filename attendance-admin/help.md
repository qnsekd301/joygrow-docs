# 문제 해결과 안전 원칙

화면이 예상과 다르거나 저장되지 않을 때는 같은 작업을 반복하기보다 아래 순서로 상태를 확인합니다.

## 저장되지 않을 때

1. 인터넷 연결을 확인합니다.
2. 선택한 날짜와 예배가 맞는지 확인합니다.
3. 읽기 전용 계정인지 확인합니다.
4. 화면을 새로고침하고 다시 로그인합니다.
5. 같은 문제가 계속되면 오류 화면과 발생 시간을 기록합니다.

## 학생이나 메뉴가 보이지 않을 때

| 증상 | 먼저 확인할 것 |
|---|---|
| 학생이 없음 | 검색어, 반, 예배 필터 |
| 교사 반이 다름 | 계정의 담당 반 설정 |
| 관리 메뉴가 없음 | 관리자 권한 수준 |
| 과거 기록이 없음 | 선택한 날짜와 학생 중복 여부 |
| 숫자가 맞지 않음 | 미확인 출석과 예배별 구분 |

## 문의할 때 함께 보낼 것

- 문제가 발생한 날짜와 시간
- 로그인한 계정의 역할
- 선택한 주일, 예배와 반
- 어떤 버튼을 눌렀는지
- 개인정보를 가린 오류 화면

## 꼭 지킬 안전 원칙

1. 확인하지 않은 출석과 결석 사유를 추측하지 않습니다.
2. 이름이 같으면 반과 예배를 함께 확인합니다.
3. 대량 가져오기 전에는 원본을 백업합니다.
4. 영구 삭제 전에 대상과 연결 기록을 확인합니다.
5. 학생·가정의 민감한 내용은 공개 채널에 공유하지 않습니다.

> 비밀번호, 연락처, 상담 내용이 보이는 화면은 그대로 외부에 보내지 마세요.
