# 문제 해결과 안전 원칙

저장되지 않거나 화면이 예상과 다르면 같은 버튼을 반복해서 누르지 말고 현재 상태부터 확인합니다.

## 저장되지 않을 때

1. 인터넷 연결을 확인합니다.
2. 화면 제목과 날짜를 확인합니다. 예배와 반도 확인합니다.
3. 읽기 전용 계정인지 확인합니다.
4. 저장 중 표시가 끝날 때까지 기다립니다.
5. 새로고침하고 다시 로그인합니다.
6. 계속되면 오류 화면과 발생 시간을 기록합니다.

## 화면별 빠른 점검

| 증상 | 먼저 확인할 것 |
|---|---|
| 학생이 없음 | 이름 검색 · 반·예배 필터 · 장결 상태 |
| 출석 숫자가 다름 | 날짜 · 미체크 학생 · 예배 구분 |
| 결석 관리가 비어 있음 | 출석 날짜와 실제 결석 기록 |
| 메뉴가 없음 | 계정 권한과 담당 범위 |
| 주일보고 제출 불가 | 5개 항목 · 최고 관리자 · PC 사용 여부 |
| 시트 연동 실패 | Apps Script 주소 · 공유 권한 · 연결 테스트 |
| 목양센터가 느림 | 로컬 실행 여부와 불필요한 온라인 동기화 |
| 공지·월간계획이 안 보임 | 홈으로 이동 · 게시/임시저장 상태 · 대상 · 게시 기간 |
| 설치 버튼이 안 보임 | 설치 여부 · 브라우저 지원 · [기기별 설치 안내](../getting-started/install.md) |

## 문의할 때 함께 보낼 것

- 문제가 발생한 날짜와 시간
- 로그인한 계정의 역할
- 선택한 주일·예배·반
- 실행한 버튼과 직전 행동
- 개인정보를 가린 오류 화면

## 꼭 지킬 안전 원칙

1. 확인하지 않은 출석과 결석 사유를 추측하지 않습니다.
2. 이름이 같으면 반·예배·생년을 함께 확인합니다.
3. 대량 가져오기 전 원본을 백업합니다.
4. 영구 삭제 전에 연결 기록을 확인합니다.
5. 학생·가정의 민감한 내용을 공개 채널에 보내지 않습니다.
6. 비밀번호·OAuth 파일·비밀키를 문서나 화면 캡처에 넣지 않습니다.

> 개인정보가 보이는 화면은 그대로 외부에 보내지 말고 반드시 가린 뒤 문의하세요.
