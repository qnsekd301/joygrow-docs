# 공지와 월간 사역계획

두 내용 모두 **출석부 홈**에서 선생님에게 보입니다. 공지는 전달·확인이 필요한 소식이고, 월간 사역계획은 여러 주의 말씀계획과 2부순서를 이어서 보는 문서입니다. 다른 메뉴로 이동하면 상단에 계속 따라오지 않습니다.

## 선생님이 읽는 순서

1. 공지 제목과 본문, 첨부 사진의 설명을 읽습니다. 확인 응답이 필요하면 **확인했어요**를 누릅니다. 아직 읽을 시간이 없으면 **나중에 다시 보기**를 사용합니다.
2. **월간 사역계획**을 열어 기간과 이번 계획의 방향을 봅니다.
3. **말씀계획**에서 해당 주 예배 날짜, 본문, 찬양, 설교 주제를 확인합니다. 어묵본문이 있는 주는 주차 날짜 옆에 작게 표시된 어묵 날짜도 확인합니다.
4. 별도로 크게 보이는 **2부순서**에서 활동, 진행 방법, 준비물을 확인합니다.
5. 다 읽은 뒤 **계획 확인했어요**를 누릅니다.

주차 표기는 예배 날짜를 기준으로 `9월 1주차`처럼 자동 계산됩니다. 공지나 계획을 관리자가 수정하여 다시 게시하면 확인 응답이 다시 필요할 수 있습니다.

## 관리자가 게시하는 방법

- 공지: 홈의 **공지 작성**에서 제목·본문·대상·게시 기간을 정하고, 모바일 미리보기를 확인한 뒤 게시합니다. `Enter`는 문단, `Shift+Enter`는 간격이 붙은 줄바꿈입니다.
- 월간 사역계획: 홈의 **월간 사역계획 → 관리**에서 기간과 주차별 말씀계획, 2부순서를 입력합니다. 기존 문서는 **AI JSON 가져오기**로 초안을 만들 수 있지만 날짜와 내용을 검토한 뒤 직접 게시해야 합니다.
- 게시 전후: 선생님 계정의 홈에서 실제 표시와 확인 응답 상태를 점검합니다. 임시저장은 선생님에게 보이지 않습니다.

작성 항목과 수정·재확인 방법은 [관리자 게시 가이드](../admin/announcements-and-plan.md)를 보세요.
