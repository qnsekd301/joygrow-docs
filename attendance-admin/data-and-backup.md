# 데이터 관리와 백업

데이터 관리 기능은 여러 기록을 한꺼번에 다루므로, 실행 전 대상과 범위를 반드시 확인해야 합니다.

## Google Sheets 연결

최고 관리자는 Apps Script 연결 상태를 확인하고 출석부 데이터를 내보내거나 가져올 수 있습니다.

1. 연결 상태를 테스트합니다.
2. 작업할 주일과 데이터 범위를 확인합니다.
3. 내보내기 또는 가져오기를 실행합니다.
4. 완료 뒤 학생 수와 최근 출석 몇 건을 대조합니다.

> 출석 시트의 날짜 칸이 비어 있으면 가져오기 과정에서 해당 날짜 기록이 삭제될 수 있습니다. 빈칸을 정리하기 전에 반드시 원본을 보관하세요.

## 데이터 점검

| 점검 항목 | 확인할 문제 |
|---|---|
| 같은 반의 중복 이름 | 중복 등록 또는 동명이인 여부 |
| 미배정 학생 | 반이 지정되지 않은 학생 |
| 등록 전 출석 | 학생 등록일보다 앞선 출석 기록 |
| 담당 반 없는 교사 | 계정과 반 연결 누락 |
| 한 반의 복수 교사 계정 | 의도한 공동 담당인지 확인 |
| 권한 없는 로그인 계정 | 역할 설정 누락 |
| 삭제 학생의 목양 기록 | 복구 또는 기록 정리 필요 |
| 생일 형식 오류 | 날짜 값 수정 필요 |

## 휴지통

삭제한 학생과 연결 기록은 휴지통에서 확인하고 복구할 수 있습니다. 영구 삭제는 복구가 어렵기 때문에 대상 학생과 과거 기록을 확인한 뒤 실행합니다.

> 대량 작업의 기본 순서는 백업 → 실행 → 표본 확인입니다.
