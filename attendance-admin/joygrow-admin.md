# JoyGrow 통제센터

출석부의 JoyGrow 통제센터에서는 출석과 칭찬으로 생성된 포인트·EXP를 확인합니다. 운영 항목과 예외도 이곳에서 관리합니다.

![출석부 JoyGrow 통제센터](../images/admin/attendance-control.png)

## 먼저 보는 것

| 영역 | 확인 내용 |
|---|---|
| 운영 현황 | 연결 학생 · 진행 이벤트 · 확인 필요 숫자 |
| 랭킹 | 반·EXP·출석·어묵 순위 흐름 |
| 학생별 포인트 | 현재 포인트와 조정 내역 |
| 성장 활동 | 활동 이름 · 포인트 · EXP · 주간 한도 |
| 이벤트 | 시작일·종료일·활성 상태 |
| 교사 지급 로그 | 누가 누구에게 무엇을 지급했는지 |

## GPT 일괄 입력

1. 개인정보를 제외한 활동 문장을 준비합니다.
2. 안내된 프롬프트 형식으로 정리합니다.
3. 변환 결과에서 이름·활동·점수를 확인합니다.
4. 동명이인과 미일치 학생을 사람이 직접 검토합니다.
5. 검토가 끝난 결과만 저장합니다.

## 잘못 지급했을 때

원본 출석·교사 지급·이벤트 기록을 먼저 찾습니다. 결과 숫자를 직접 맞추기보다 잘못된 지급 건을 취소해 감사 기록이 남도록 처리합니다.

[포인트와 EXP 기준 보기](../student/points-and-exp.md)

> 포인트는 결과이고 출석과 실제 관찰 기록이 원본입니다.
