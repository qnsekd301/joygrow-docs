# 계정과 권한

계정 권한은 볼 수 있는 정보와 실행할 수 있는 작업을 결정합니다. 실제 역할에 필요한 만큼만 부여하세요.

## 권한 구분

| 권한 | 사용 범위 |
|---|---|
| 최고 관리자 | 모든 운영 기능, 계정·반·연동·휴지통 관리 |
| 부관리자 | 허용된 관리자 기능과 출석 운영 |
| 읽기 전용 관리자 | 자료 조회 가능, 저장·수정·삭제 제한 |
| 교사 | 담당 반을 중심으로 출석과 필요한 기능 사용 |

## 계정 관리

1. 계정을 만들기 전에 같은 아이디가 있는지 확인합니다.
2. 사용자 이름과 담당 반을 선택합니다.
3. 역할에 맞는 권한만 부여합니다.
4. 교사 계정은 담당 반이 정확한지 확인합니다.
5. 역할이 끝난 계정은 즉시 정리합니다.

## 메뉴가 보이지 않을 때

로그인한 계정의 권한과 담당 반을 먼저 확인합니다. 읽기 전용 계정은 버튼이 없거나 비활성화될 수 있고, 최고 관리자 전용 기능은 일반 관리자에게 표시되지 않을 수 있습니다.

> 편의를 위해 높은 권한을 주기보다, 맡은 일에 맞는 권한을 주는 것이 안전합니다.
