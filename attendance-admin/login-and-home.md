# 로그인과 관리자 홈

로그인하면 관리자 홈에서 오늘 처리해야 할 일을 우선순위대로 확인할 수 있습니다.

![오늘의 사역이 보이는 관리자 홈](../images/admin/attendance-home.png)

## 로그인

1. 발급받은 아이디와 비밀번호를 입력합니다.
2. 관리자 모드로 들어갑니다.
3. 이름과 권한이 맞는지 확인합니다.

공용 PC에서는 업무가 끝난 뒤 반드시 로그아웃하세요.

## 홈에서 먼저 볼 것

| 영역 | 의미 |
|---|---|
| 오늘의 사역 흐름 | 출석·결석·미체크·확인 필요 현황 |
| 바로가기 | 출결, 목양센터, JoyGrow, 재정센터 이동 |
| 오늘의 돌봄 | 오늘 연락하거나 우선 확인할 학생 |
| JoyGrow 운영비서 | 이벤트와 운영상 확인이 필요한 항목 |
| 미확인 반 | 아직 출석 기록을 끝내지 않은 반 |

출석 미확인 → 결석 사유 누락 → 연속 결석 → 주일보고 순서로 확인하면 됩니다. 읽기 전용 관리자는 자료가 보여도 저장·삭제가 제한됩니다.

> 홈의 숫자가 줄어드는 것보다, 숫자 뒤에 있는 학생을 정확히 확인하는 것이 먼저입니다.
