# 주일보고

주일보고는 출석 기록을 최종 확인하고 교회 보고로 연결하는 마지막 단계입니다.

## 제출 전 확인

| 항목 | 확인 내용 |
|---|---|
| 학생 | 1·2부 예배별 출석 인원 |
| 교사 | 예배별 교사 출석 인원 |
| 방문자 | 해당 주일 방문 인원 |
| 새가족 | 새로 등록하거나 방문한 학생 |
| 헌금 | 예배별 헌금 금액과 입력 상태 |

## 보고 순서

1. 보고할 주일 날짜를 선택합니다.
2. 미확인 반이 남아 있는지 확인합니다.
3. 1부와 2부의 학생·교사 인원을 점검합니다.
4. 방문자, 새가족과 헌금을 입력합니다.
5. 특이사항을 정리한 뒤 제출합니다.

최고 관리자는 PC에서 보고 내용을 카카오톡용 문장으로 복사할 수 있습니다. 교회 홈페이지로 제출하기 전에는 숫자와 날짜를 한 번 더 확인하세요.

> 제출은 기록의 끝이 아니라, 확인이 끝났다는 표시입니다.
