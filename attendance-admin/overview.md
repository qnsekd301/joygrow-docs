# 출석부 한눈에 보기

출석부는 이번 주에 나와야 할 학생을 확인하고 결석한 학생을 빠르게 찾도록 구성되어 있습니다. 선생님 홈에는 전체 공지와 월간계획도 표시됩니다. 아래 표는 관리자에게 추가로 보이는 운영 메뉴를 포함합니다.

![전체 메뉴 화면](../images/admin/attendance-all-menu.png)

## 매주 사용하는 기본 메뉴

| 메뉴 | 언제 사용하나요? | 완료 기준 |
|---|---|---|
| 결석 | 출석 확인 뒤 | 사유 누락과 연속 결석 검토 완료 |
| 홈 | 로그인 직후 | 오늘 만나야 할 학생과 확인 필요 항목 파악 |
| 반별 출석 | 예배 전후 | 출석·결석·미체크 상태 확인 |
| 학생 | 명단 변경 시 | 이름·반·예배·연락 정보 확인 |
| 주일보고 | 주일 마감 전 | 숫자 확인 · 미체크 반 0개 |
| 전체 | 운영 기능 사용 시 | 필요한 도구를 찾아 업무 처리 |

## 주일 운영 순서

1. **홈**에서 오늘 만나야 할 학생과 미체크 숫자를 봅니다.
2. **반별 출석**에서 실제로 만난 학생을 기록합니다.
3. **결석**에서 만나지 못한 학생과 이유를 확인합니다.
4. 연락이 필요한 학생은 담당 선생님과 다음 행동을 정합니다.
5. 반복해서 만나지 못한 학생은 **장결 관리**와 **목양센터**로 이어 갑니다.
6. 목양 확인이 끝난 뒤 **주일보고**를 마감합니다.

## 기록의 기준

- 날짜·예배·반을 먼저 확인합니다.
- 빈칸을 결석으로 추측하지 않습니다.
- 동명이인은 반과 예배로 구분합니다.
- 같은 학생을 호칭이나 띄어쓰기로 중복 생성하지 않습니다.
- 민감한 가정사는 필요한 범위만 기록합니다.

> 누구를 만났는지 확인하고 만나지 못한 아이에게 다시 다가가는 흐름입니다.
