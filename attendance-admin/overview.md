# 출석부 한눈에 보기

관리자 화면은 자주 쓰는 여섯 메뉴와 전체 운영 도구를 분리해, 주일에는 핵심 업무에 집중하고 필요할 때만 관리 기능을 열도록 구성되어 있습니다.

![전체 메뉴 화면](../images/admin/attendance-all-menu.png)

## 매주 사용하는 기본 메뉴

| 메뉴 | 언제 사용하나요? | 완료 기준 |
|---|---|---|
| 홈 | 로그인 직후 | 오늘의 사역 흐름과 확인 필요 항목 파악 |
| 반별 출석 | 예배 전후 | 모든 학생이 출석·결석 또는 사유 상태 |
| 결석 | 출석 확인 뒤 | 사유 누락과 연속 결석 검토 완료 |
| 학생 | 명단 변경 시 | 이름·반·예배·연락 정보 확인 |
| 주일보고 | 주일 마감 전 | 5개 숫자 입력, 미체크 반 0개 |
| 전체 | 운영 기능 사용 시 | 필요한 도구를 찾아 업무 처리 |

## 주일 운영 순서

1. **홈**에서 미체크와 확인 필요 숫자를 봅니다.
2. **반별 출석**에서 선택한 날짜와 반을 확인합니다.
3. **결석**에서 사유 누락과 연속 결석 학생을 봅니다.
4. 후속 행동이 필요하면 **목양센터** 또는 **장결 관리**로 이어 갑니다.
5. **주일보고**의 학생·교사·방문·새가족·헌금을 저장합니다.
6. 오류가 의심되면 **데이터 점검**을 실행합니다.

## 기록의 기준

- 날짜, 예배, 반을 먼저 확인합니다.
- 빈칸을 결석으로 추측하지 않습니다.
- 동명이인은 반과 예배로 구분합니다.
- 같은 학생을 호칭이나 띄어쓰기로 중복 생성하지 않습니다.
- 민감한 가정사는 필요한 범위만 기록합니다.

> 출석 → 결석 사유 → 목양 → 주일보고가 하나의 기록 흐름입니다.
