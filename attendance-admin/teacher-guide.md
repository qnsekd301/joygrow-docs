# 선생님 사용법

출석부 주소는 [songrim-attendance.netlify.app](https://songrim-attendance.netlify.app)입니다. 받은 계정으로 로그인하면 맡은 역할에 맞는 메뉴가 보입니다. 휴대전화에서는 화면 아래쪽 메뉴로 이동합니다.

## 처음 로그인했다면

1. 화면의 이름·부서·담당 반을 확인합니다. 다르면 입력을 시작하지 말고 관리자에게 알려 주세요.
2. 홈의 공지와 월간 사역계획을 읽습니다. 확인 응답이 필요한 내용은 읽은 뒤 확인합니다.
3. 출석 메뉴에서 예배 날짜와 반을 선택합니다. 같은 이름의 학생은 반과 예배를 함께 확인합니다.
4. 만난 학생은 출석, 만나지 못한 학생은 확인한 결석 사유를 기록합니다. 아직 확인하지 않은 학생은 미체크로 둡니다.
5. JoyGrow 화면에서 직접 본 행동만 칭찬합니다. 학생에게 이유를 설명하고 지급 결과를 확인합니다.
6. 연락·심방이 필요한 학생은 **심방요청**으로 관리자에게 전달합니다.

일반 선생님 하단에는 **홈 · 출석 · JoyGrow · 통계 · 심방요청**이 보입니다. 권한에 따라 버튼 이름이나 표시 범위가 다를 수 있습니다. 출석을 담당하지 않는 칭찬 지원 선생님은 **홈 · 칭찬 · 내 계정**을 사용하며, 주일 하루 최대 3명의 서로 다른 학생에게 칭찬할 수 있습니다.

## 주일에 흔히 헷갈리는 일

| 상황 | 처리 |
|---|---|
| 출석 버튼을 잘못 눌렀어요 | 먼저 날짜와 학생을 다시 확인한 뒤 수정합니다. 포인트가 연결됐다면 지급 기록도 확인합니다. |
| 미체크가 남았어요 | 아직 확인하지 않은 상태입니다. 자동으로 결석이 되지 않으므로 사실을 확인한 뒤 입력합니다. |
| 우리 반 학생이 안 보여요 | 날짜·예배·반과 검색어를 확인합니다. 그래도 없으면 관리자에게 명단 확인을 요청합니다. |
| 칭찬 버튼이 비활성화됐어요 | 학생·반·선생님별 한도에 도달했을 수 있습니다. 다른 항목으로 대신 지급하지 않습니다. |
| 공지나 계획을 다시 보고 싶어요 | 홈으로 돌아갑니다. 다른 화면 상단에는 고정되지 않습니다. |
