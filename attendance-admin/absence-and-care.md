# 결석과 장결 관리

결석 화면은 단순한 결석자 명단이 아니라, 연락이 필요한 학생을 우선순위로 나누고 장기 관리로 연결하는 화면입니다.

![결석 관리 화면](../images/admin/attendance-ministry.png)

## 결석 관리의 세 탭

| 탭 | 보는 내용 | 관리자 행동 |
|---|---|---|
| 관리 필요 | 2주·3주 이상 연속 결석, 갑작스러운 결석 | 연락 여부와 목양 필요성 판단 |
| 주별 결석 | 선택한 주일의 결석자와 사유 | 사유 누락 보완 |
| 흐름 분석 | 학생별 출석 변화 | 평소와 달라진 흐름 확인 |

저장된 카톡 일괄전송 명단은 보호자 연락이 필요한 학생을 모아 확인하는 보조 기능입니다. 발송 전 이름·연락처·문장을 사람이 다시 확인합니다.

## 장결 특별 관리

![장결 특별 관리 화면](../images/admin/attendance-long-term.png)

1. 학생과 현재 반을 확인합니다.
2. 시작일, 사유와 필요한 설명을 입력합니다.
3. 다음 연락일과 담당 행동을 정합니다.
4. 오늘 확인했다면 확인 상태를 갱신합니다.
5. 학생이 돌아오면 복귀일을 기록하고 장결 상태를 종료합니다.

## 상태별 기준

| 상태 | 기록 원칙 |
|---|---|
| 사유 누락 | 담당 교사나 보호자에게 확인 후 입력 |
| 1회 결석 | 이유 기록, 필요할 때 안부 확인 |
| 연속 결석 | 이전 목양 기록 확인 후 다음 연락 결정 |
| 예정 결석 | 기간 전체와 복귀 예정일 기록 |
| 장기 결석 | 장결 관리와 목양센터를 함께 사용 |

> 결석 횟수보다 중요한 것은 마지막 연락과 다음 행동이 기록되어 있는가입니다.
