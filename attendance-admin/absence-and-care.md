# 결석과 목양 연결

결석 화면은 이유를 적는 곳이면서, 다시 만나기 위한 다음 행동을 정하는 출발점입니다.

## 먼저 구분하기

| 상태 | 관리자 행동 |
|---|---|
| 사유 누락 | 담당 교사에게 확인하고 이유 보완 |
| 1회 결석 | 사유 기록, 필요한 경우 안부 확인 |
| 연속 결석 | 연락 여부와 목양 필요성 확인 |
| 장기 결석 | 기간·사유를 정리하고 장기결석 관리로 이동 |
| 복귀 | 복귀일을 확인하고 장기결석 상태 종료 |

## 목양센터로 이어 가기

1. 학생, 반과 결석 기간을 확인합니다.
2. 이미 기록된 목양 내용이 있는지 먼저 찾습니다.
3. 연락, 기도, 심방 등 다음 행동을 정합니다.
4. 담당자와 예정일을 남깁니다.
5. 처리 뒤 결과와 다음 약속을 기록합니다.

같은 학생을 호칭만 달리해 중복 등록하지 말고 학생 명단의 한 이름을 기준으로 기록하세요. 민감한 상담 내용은 필요한 범위만 적습니다.

> 출석은 사실, 결석 사유는 이해, 목양 기록은 다음 행동입니다.
