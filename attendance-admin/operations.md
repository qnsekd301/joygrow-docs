# 전체 메뉴

전체 메뉴는 23개의 기능을 예배·학생, 목양·소통, 운영·관리로 나누어 보여 줍니다. 자주 쓰는 기능은 별표로 즐겨찾기에 올릴 수 있습니다.

![전체 메뉴 화면](../images/admin/attendance-all-menu.png)

## 화면 사용법

1. 상단 검색창에 메뉴 이름을 입력합니다.
2. 자주 쓰는 메뉴는 카드 오른쪽 위 별표를 누릅니다.
3. 즐겨찾기 영역에서 한 번에 실행합니다.
4. 권한이 없는 메뉴가 보이지 않는 것은 정상입니다.

## 예배·학생

| 기능 | 용도 |
|---|---|
| 홈·출석·결석·학생·주일보고 | 주일 핵심 운영 |
| JoyGrow | 포인트·EXP·성장 활동 관리 |
| 생일 | 지난달·이번 달·다음 달 생일 확인 |
| 기도·헌금 | 예배별 대표기도·헌금위원 배정 |
| 새가족 | 방문·등록·교육·정착 관리 |

## 목양·소통

| 기능 | 용도 |
|---|---|
| 목양센터 | 목양 기록과 후속 할 일 |
| 메시지 | 교사 안내 작성과 발송 내역 |
| 장결 관리 | 장기 결석 확인, 연락과 복귀 처리 |

## 운영·관리

| 기능 | 용도 |
|---|---|
| 재정센터 | 예산·지출·재정 시트 확인 |
| 계정·반 | 사용자 권한, 담당 반과 학생 이동 |
| 구글 시트 | 데이터 내보내기·가져오기 연동 |
| 데이터 점검 | 중복·누락·잘못된 연결 검사 |
| 휴지통 | 삭제 학생 확인·복구·영구 삭제 |

> 도구가 많아도 학생·날짜·예배라는 기준은 항상 같습니다.
