# 운영 기능 모아보기

출석부의 전체 메뉴에는 주일 운영에 필요한 기능이 한곳에 모여 있습니다.

## JoyGrow

![출석부 JoyGrow 통제센터](../images/admin/attendance-control.png)

포인트, EXP, 성장 활동, 이벤트와 교사 지급 내역을 관리합니다. 잘못 지급한 내역은 원본 기록을 확인한 뒤 취소합니다.

## 운영 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 목양센터 | 학생별 목양 기록과 후속 할 일 관리 |
| 재정센터 | 재정 현황, 예정 지출과 예산 확인 |
| 생일 | 지난달·이번 달·다음 달 생일 확인 |
| 기도·헌금위원 | 주일 담당 학생 배정과 확인 |
| 새가족 | 방문·등록 학생의 정착 과정 관리 |
| 메시지 | 교사 안내 전송과 발송 내역 관리 |
| 장기결석 | 장기 관리, 확인 상태와 복귀 처리 |

각 기능에서 같은 학생을 새로 입력하지 말고 학생 명단과 연결해 사용합니다. 재정과 개인정보는 필요한 권한을 가진 사람만 열람합니다.

> 운영 기능은 따로 보여도, 기준이 되는 학생과 주일 기록은 하나입니다.
