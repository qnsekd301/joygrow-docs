# 송림소년부 출석부 관리자 공식 가이드

송림소년부 출석부의 실제 화면과 운영 코드를 기준으로 만든 관리자용 설명서입니다. 출석 기록부터 결석 확인, 목양, 주일보고와 데이터 관리까지 화면을 보며 그대로 따라 할 수 있습니다.

![출석부 관리자 홈](../images/admin/attendance-home.png)

## 이 설명서의 화면 표시

화면 이미지의 보라색 번호는 모든 페이지에서 같은 기준으로 읽습니다.

| 번호 | 뜻 |
|---:|---|
| ① | 지금 열어 둔 화면의 이름과 상단 작업 버튼 |
| ② | 실제로 확인하고 입력하는 업무 영역 |
| ③ | 홈·출석·결석·학생·주일보고·전체 메뉴 이동 |

## 관리자가 이어 주는 흐름

`주일 준비 → 출석 확인 → 결석 사유 → 목양 행동 → 주일보고 → 데이터 점검`

| 흐름 | 관리자 역할 |
|---|---|
| 주일 준비 | 반·학생·교사 계정과 담당 확인 |
| 출석 기록 | 날짜·예배·반을 확인하고 출결과 성장 포인트 기록 |
| 결석 관리 | 사유 누락, 연속 결석과 장결 학생 확인 |
| 목양 연결 | 연락·기도·심방·다음 약속을 한 학생 기록으로 연결 |
| 운영 마감 | 주일보고를 저장하고 미체크 반 확인 |
| 안전 관리 | 권한·백업·데이터 정합성과 휴지통 확인 |

> 기록의 목적은 통계가 아니라, 한 아이도 놓치지 않고 다시 만나는 것입니다.
