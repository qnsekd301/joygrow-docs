# 송림소년부 출석부 관리자 공식 가이드

송림소년부 출석부는 출석 숫자를 입력하는 데서 끝나지 않습니다. 결석한 아이를 발견하고, 필요한 목양을 이어 가며, 주일보고까지 놓치지 않도록 돕는 운영 도구입니다.

![출석부 관리자 홈](../images/admin/attendance-home.png)

## 이 설명서에서 다루는 것

| 흐름 | 할 수 있는 일 |
|---|---|
| 주일 준비 | 학생·반·교사 계정과 담당 확인 |
| 출석 기록 | 예배별 출석, 결석 사유, 오목과 재량 기록 |
| 목양 연결 | 연속·장기 결석을 발견하고 후속 조치 관리 |
| 보고와 운영 | 주일보고, 새가족, 생일, 기도·헌금위원 관리 |
| 안전 관리 | 권한, 데이터 점검, 백업과 휴지통 관리 |

## 처음이라면

1. 관리자 홈에서 오늘 처리할 항목을 확인합니다.
2. 출석에서 날짜와 예배를 먼저 확인합니다.
3. 미확인 학생과 결석 사유를 정리합니다.
4. 후속 조치가 필요한 학생을 목양센터로 연결합니다.
5. 마지막으로 주일보고를 작성하고 제출합니다.

> 기록의 목적은 통계가 아니라, 한 아이도 놓치지 않고 다시 만나는 것입니다.
