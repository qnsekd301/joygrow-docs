# 문제 해결과 문의

문제가 생기면 같은 저장·구매·지급 버튼을 여러 번 누르지 마세요. **날짜·계정·현재 기록**을 먼저 확인하면 중복 처리를 피할 수 있습니다.

![다시 시도 안내](../.gitbook/assets/error-retry.png)

## 가장 먼저 확인하기

1. 인터넷 연결을 확인하고 화면이 완전히 열릴 때까지 기다립니다.
2. 출석부는 **주일 날짜·예배·반**, JoyGrow는 **학생 이름·부서·반**을 확인합니다.
3. 방금 처리한 내용은 기록·주문 내역에서 이미 반영됐는지 먼저 찾습니다.
4. 반영되지 않았다면 한 번 새로고침하고 다시 로그인합니다. 계속 같은 오류가 나면 화면을 캡처해 담당자에게 알립니다.

## 상황별 해결

| 증상 | 확인할 순서 |
|---|---|
| 학생 이름이 안 나와요 | 이름의 띄어쓰기 → 예배·반 필터 → 학생의 활성·장결 상태 → 관리자에게 명단 확인 요청 |
| 비밀번호를 잊었어요 | 담당 선생님이나 관리자에게 본인 확인 후 초기화를 요청합니다. 공개 채팅에 PIN을 올리지 않습니다. |
| 출석 미체크가 남아요 | 아직 출결을 정하지 않은 학생을 확인합니다. 모르는 상태를 결석으로 임의 처리하지 않습니다. |
| 포인트가 예상과 달라요 | JoyGrow 최근 활동·보관함의 날짜 → 출석 또는 칭찬 원본 기록 → 관리자 지급 로그 순서로 확인합니다. |
| 칭찬 버튼이 안 눌려요 | 해당 학생·반·지원 선생님의 주간/하루 한도와 담당 범위를 확인합니다. |
| 상품 구매 뒤 화면이 멈췄어요 | 구매 버튼을 다시 누르기 전에 주문 내역과 포인트 잔액을 확인합니다. |
| 공지·월간계획이 안 보여요 | 출석부 **홈**으로 돌아와 게시 기간·대상과 인터넷 연결을 확인합니다. 임시저장은 선생님에게 보이지 않습니다. |
| 메뉴가 없어요 | 로그인 계정의 역할과 담당 반을 확인합니다. 권한에 따라 표시 메뉴가 다릅니다. |
| 설치 버튼이 없어요 | 이미 설치했거나 브라우저가 설치 프롬프트를 지원하지 않을 수 있습니다. [기기별 설치 안내](../getting-started/install.md)를 따르세요. |

## 관리자에게 문제를 전달할 때

앱 이름, 사용한 화면, 발생 날짜·시간, 선택한 주일·예배·반 또는 학생 이름, 누른 버튼, 화면에 나온 오류 문구를 알려 주세요. 캡처에는 학생 전화번호·보호자 연락처·상담 내용·비밀번호·관리자 인증정보가 보이지 않도록 가립니다.

긴급한 개인정보 노출이나 잘못된 대량 지급은 반복 시도하지 말고 즉시 운영 관리자에게 알립니다. 자세한 출석부 운영 점검은 [출석부 문제 해결](../attendance-admin/help.md)을 보세요.
