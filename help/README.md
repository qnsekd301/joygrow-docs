# 자주 묻는 질문

문제가 생기면 같은 버튼을 반복해서 누르기보다 아래 순서로 확인하세요.

![주인공 화면의 다시 시도 안내](../images/student/error-retry.png)

## 포인트가 안 들어왔어요

화면을 새로고침한 뒤, 선생님에게 출석 또는 칭찬 기록이 완료됐는지 확인해 달라고 합니다. [자세히 보기](points.md)

## 이름이 검색되지 않아요

이름의 띄어쓰기를 확인하고, 선생님에게 출석부와 JoyGrow의 활성 학생·부서·반 정보를 확인해 달라고 합니다. [자세히 보기](student-search.md)

## 비밀번호를 잊었어요

비밀번호를 공개 대화방에 쓰지 말고 담당 선생님 또는 김환희 강도사에게 재설정을 요청합니다. [자세히 보기](password.md)

## 메뉴나 버튼이 보이지 않아요

로그인한 역할, 담당 부서와 반을 확인합니다. 주간 한도에 도달한 칭찬 버튼은 `완료` 상태로 비활성화됩니다.

## 상품을 주문했는데 보이지 않아요

포인트 상점의 주문 내역을 먼저 확인합니다. 포인트만 빠지고 주문 내역이 없다면 학생·부서·반, 상품, 발생 시간을 김환희 강도사에게 알려 주세요.

> **문의**  
> 오류나 궁금한 점은 김환희 강도사에게 문의해 주세요. 비밀번호, 전화번호, 부모 연락처, 상담 내용은 보내지 마세요.
