# 자주 묻는 질문

JoyGrow 사용 중 자주 만나는 문제를 빠르게 확인합니다.

## 먼저 확인하세요

- 학생 이름이 검색되지 않으면 이름과 부서를 다시 확인합니다.
- 포인트가 다르면 최근 지급 기록과 관리자 변경 기록을 확인합니다.
- 비밀번호를 잊으면 담당 선생님 또는 관리자에게 요청합니다.
- 메뉴가 보이지 않으면 로그인한 역할과 담당 범위를 확인합니다.

> 기억하세요  
> 문제가 계속되면 화면 이름, 학생의 부서·반, 발생 시간을 함께 알려 주세요. 비밀번호는 보내지 마세요.
