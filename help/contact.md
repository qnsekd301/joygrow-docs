# 문의할 때 이렇게 보내세요

오류나 궁금한 점은 **김환희 강도사**에게 문의해 주세요.

## 함께 보내면 좋은 정보

1. 사용한 화면: 예) 선생님 `JoyGrow`, 학생 `포인트 상점`
2. 대상 학생의 이름·부서·반
3. 발생한 날짜와 시간
4. 누른 버튼 또는 기록한 활동
5. 화면에 나온 안내 문구
6. 개인정보를 가린 화면 캡처

## 보내면 안 되는 정보

- 비밀번호와 관리자 인증정보
- 전화번호와 부모 연락처
- 상담·목양 기록
- API 키, 환경변수, 내부 보안 설정

> **기억하세요**  
> 긴급하게 여러 학생에게 같은 문제가 생겨도, 같은 작업을 반복 실행하기 전에 현재 기록을 먼저 보존하고 문의하세요.
