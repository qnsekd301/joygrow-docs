# 학생이 검색되지 않을 때

학생 로그인 검색과 선생님 담당 학생 목록은 등록·활성 상태와 부서·반 정보를 기준으로 합니다.

## 이렇게 확인하세요

1. 이름을 띄어쓰기 없이 다시 입력합니다.
2. 동명이인이 있는지 부서와 반을 확인합니다.
3. 선생님은 현재 로그인한 담당 반 또는 담당 부서가 맞는지 확인합니다.
4. 출석부에 새로 등록하거나 반을 옮긴 학생이면 연결이 완료됐는지 확인합니다.
5. 계속 보이지 않으면 김환희 강도사에게 등록 상태를 요청합니다.

## 문의할 때 알려 줄 것

- 학생 이름
- 부서와 반
- 검색한 화면 이름
- 문제가 발생한 날짜와 시간

> **기억하세요**  
> 전화번호, 부모 연락처, 비밀번호와 상담 내용은 공개 대화방에 올리지 마세요.
