# 비밀번호 문제

주인공과 선생님은 숫자 4자리 비밀번호를 사용하고, 독립 관리자는 별도 관리자 계정을 사용합니다.

## 로그인이 되지 않을 때

1. 먼저 선택한 이름과 부서·반을 확인합니다.
2. 숫자 4자리를 천천히 다시 입력합니다.
3. 계속 틀리면 여러 번 추측하지 말고 재설정을 요청합니다.

## 재설정이 필요할 때

- 주인공: 담당 선생님 또는 김환희 강도사에게 본인과 부서·반을 알립니다.
- 선생님: 김환희 강도사에게 본인 계정과 담당 반을 알립니다.
- 관리자: 공개 대화방이 아닌 정해진 관리자 연락 방법을 사용합니다.

## 로그인한 뒤

주인공은 설정에서 새 숫자 4자리 비밀번호로 바꿀 수 있습니다. 공용 기기에서는 사용을 마친 뒤 반드시 로그아웃합니다.

> **기억하세요**  
> 기존 비밀번호나 새 비밀번호를 문서, 화면 캡처, 카카오톡 메시지에 쓰지 마세요.
