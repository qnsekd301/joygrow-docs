# 포인트가 반영되지 않을 때

포인트는 출석부 자동 기록과 선생님 직접 칭찬의 두 경로로 들어옵니다.

## 주인공이 확인할 순서

1. 화면을 한 번 새로고침합니다.
2. 보관함의 최근 성장 기록에서 활동과 날짜를 확인합니다.
3. 담당 선생님에게 해당 활동이 저장됐는지 물어봅니다.

## 선생님이 확인할 순서

1. 출석·어묵·재량이면 출석부 저장 상태를 확인합니다.
2. 칭찬이면 최근 지급 기록과 버튼의 주간 제한 문구를 확인합니다.
3. 같은 항목을 다시 누르지 말고, 연결 실패 안내가 있었는지 확인합니다.
4. 계속 다르면 학생의 이름·부서·반, 활동, 날짜를 김환희 강도사에게 전달합니다.

## 포인트는 맞지만 EXP가 다르다면

활동별 포인트와 EXP 숫자는 같지 않습니다. [포인트 지급 기준표](../teacher/point-policy.md)에서 활동별 값을 확인한 뒤 문의하세요.

> **기억하세요**  
> 포인트 상점 주문은 포인트를 차감하지만 EXP는 별도 성장 기록으로 유지됩니다.
