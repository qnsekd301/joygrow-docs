# 3분 만에 시작하기

내 역할에 맞는 순서만 따라 하면 바로 사용할 수 있습니다.

## 주인공(학생)

1. JoyGrow 학생 화면에서 이름을 검색합니다.
2. 부서와 반을 확인한 뒤 내 이름을 고릅니다.
3. 숫자 4자리 비밀번호를 입력합니다.
4. 홈에서 포인트와 오늘의 성장 여정을 확인합니다.

## 선생님

1. 송림소년부 출석부에서 이름과 숫자 4자리 비밀번호로 로그인합니다.
2. 하단 `출석`에서 담당 반의 출석·어묵·재량을 기록합니다.
3. 하단 `JoyGrow`에서 실제로 확인한 칭찬을 누릅니다.
4. 지급 완료 문구와 남은 주간 한도를 확인합니다.

## 관리자

1. 목적에 맞는 관리자 화면으로 들어갑니다.
2. 일상 출석 연동과 교사 지급 기록은 출석부의 `JoyGrow 통제센터`에서 봅니다.
3. 학생·포인트·포인트 상점·믿음 원정대 설정은 JoyGrow 독립 관리자에서 관리합니다.
4. 저장 전 대상 학생, 숫자, 사유를 다시 확인합니다.

> **기억하세요**  
> 학생 화면, 출석부, 독립 관리자 화면은 로그인 방법과 메뉴가 서로 다릅니다.
