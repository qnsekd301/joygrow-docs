# 앱 접속·설치

앱을 설치하지 않아도 아래 주소를 브라우저에서 열면 사용할 수 있습니다.

| 앱 | 주소 | 주 사용자 |
|---|---|---|
| 송림소년부 출석부 | [songrim-attendance.netlify.app](https://songrim-attendance.netlify.app) | 선생님·관리자 |
| JoyGrow | [songrim-point.netlify.app](https://songrim-point.netlify.app/student/login) | 학생·관리자 |

## 설치할 수 있는 브라우저

Chrome이나 Edge 등에서 설치가 가능하다고 판단되면 화면에 작은 **앱 설치** 버튼이 나타납니다. 이 버튼을 누르면 브라우저의 설치 확인 창이 열립니다. 설치를 완료하면 홈 화면이나 PC 앱 목록에서 바로 열 수 있습니다.

버튼이 없다고 앱 오류는 아닙니다. 이미 설치했거나, 브라우저가 `beforeinstallprompt` 설치 기능을 제공하지 않거나, 아직 설치 가능하다고 판단하지 않은 경우에는 표시되지 않습니다. 접속 즉시 설치 확인 창을 강제로 띄우는 기능은 없습니다.

## iPhone·iPad

Safari에서 해당 앱 주소를 연 뒤 **공유 → 홈 화면에 추가**를 선택합니다. iPhone Safari에는 위의 앱 설치 버튼이 나타나지 않을 수 있으며, 카카오톡 안에서 연 화면에서는 Safari로 다시 열어 진행합니다.

## 카카오톡 링크로 들어왔을 때

카카오톡 내부 브라우저에서 설치 버튼이 보이지 않으면 메뉴에서 **다른 브라우저로 열기**를 선택합니다. Android는 Chrome 등 설치 지원 브라우저, iPhone은 Safari에서 주소를 엽니다.

## 설치 뒤 확인

1. 기기의 홈 화면 또는 PC 앱 목록에 아이콘이 생겼는지 확인합니다.
2. 아이콘으로 앱을 열고 원래 계정으로 로그인합니다.
3. 설치 안내나 버튼이 사라져도 정상입니다. 새 기기에서는 다시 로그인해야 할 수 있습니다.

> 설치 여부와 관계없이 같은 운영 주소와 기록을 사용합니다. 설치가 안 되더라도 브라우저에서 바로 업무를 계속할 수 있습니다.
