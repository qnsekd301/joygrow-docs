# 역할별 시작 안내

송림소년부는 **출석부**와 **JoyGrow**를 함께 사용합니다. 처음에는 자신의 역할에 맞는 화면 하나만 익히면 됩니다.

| 역할 | 로그인할 곳 | 주로 하는 일 | 다음 페이지 |
|---|---|---|---|
| 학생 | JoyGrow 학생 로그인 | 내 포인트·여정 확인, 열매상점 주문 | [학생 로그인과 홈](../student/README.md) |
| 담임 선생님 | 출석부 | 담당 반 출석, 어묵, 재량, 칭찬, 돌봄 | [선생님 시작하기](../teacher/README.md) |
| 칭찬 지원 선생님 | 출석부 | 배정된 1부 또는 2부 학생의 칭찬 | [칭찬 지원 선생님](../teacher/support-teacher.md) |
| 부서 관리자 | 출석부 | 담당 부서 출석·주일보고·운영 확인 | [관리자 시작하기](../admin/README.md) |
| 총관리자 | 출석부 및 JoyGrow 관리자 | 1·2부 통합, 계정, 공지·월간계획, 포인트·상품·정책 | [관리자 시작하기](../admin/README.md) |

## 첫 3분

1. [앱 접속·설치](install.md)에 있는 주소를 엽니다. 앱 설치 없이도 브라우저에서 사용할 수 있습니다.
2. 계정에 맞는 방식으로 로그인합니다. 학생은 **이름 검색 → 부서·반 확인 → 4자리 비밀번호**, 선생님은 출석부 계정으로 로그인합니다.
3. 홈에서 본인의 부서·반과 오늘 날짜를 확인합니다.
4. 하단 메뉴 또는 PC의 메뉴에서 필요한 일을 선택합니다. 메뉴가 보이지 않는다면 먼저 계정 권한과 담당 범위를 확인합니다.

## 자주 쓰는 말

| 말 | 뜻 |
|---|---|
| 1부·2부 | 예배 부서. 같은 이름의 학생도 부서와 반으로 구분합니다. |
| 미체크 | 아직 출석도 결석도 확인하지 않은 상태. 결석과 다릅니다. |
| 어묵 | 출석부에서 횟수 구간을 기록하는 말씀 활동. |
| 재량 | 선생님이 출석부에서 확인해 기록하는 칭찬 포인트 항목. |
| 포인트(P) | 열매상점에서 쓸 수 있는 잔액. |
| EXP | 성경 인물과 믿음원정의 성장 경험치. 상품을 사도 차감되지 않습니다. |
| 장기결석 예정 | 돌아올 날짜를 아는 계획된 결석. 일반 결석 집계와 구분합니다. |
| 장결 | 복귀 시점을 정하기 어려워 일반 출석 대상과 분리해 돌보는 상태. |

> 처음 입력하기 전에는 항상 **날짜 → 부서 → 반 → 학생** 순서로 확인하세요.
