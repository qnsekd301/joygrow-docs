# JoyGrow란?

JoyGrow는 실물 포인트의 분실과 계산 부담을 줄이고, 아이들의 예배와 좋은 행동을 눈에 보이는 성장 여정으로 보여 주는 송림소년부 시스템입니다.

## 왜 만들었나요?

- 선생님이 매번 선물을 고르고 종이 포인트를 관리하는 수고를 줄입니다.
- 주인공은 어떤 노력을 하면 포인트를 얻는지 쉽게 알 수 있습니다.
- 출석부의 기록과 JoyGrow가 연결되어 포인트를 빠뜨리지 않고 반영합니다.
- 포인트를 모으는 과정이 성경 인물 성장과 믿음 원정대로 이어집니다.

## 이렇게 이어져요

1. 선생님이 출석부에서 출석·어묵·재량을 기록합니다.
2. 실제로 본 좋은 행동은 `JoyGrow`에서 칭찬합니다.
3. 주인공에게 포인트와 EXP가 함께 쌓입니다.
4. 주인공은 성경 인물을 키우고 퀘스트와 믿음 원정대를 확인합니다.
5. 모은 포인트로 포인트 상점의 상품을 주문합니다.

> **기억하세요**  
> 설명서에서는 학생을 JoyGrow 이야기의 **주인공**이라고 부릅니다.
