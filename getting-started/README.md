# JoyGrow 한눈에 보기

실물 포인트의 분실과 계산 부담을 줄이고, 아이들의 예배와 좋은 행동을 눈에 보이는 성장으로 보여 줍니다.

## 역할별로 하는 일

| 역할 | 하는 일 |
|---|---|
| 주인공(학생) | 내 포인트, EXP, 퀘스트와 성경 인물 확인 |
| 선생님 | 출석을 기록하고 직접 본 좋은 행동을 칭찬 |
| 관리자 | 학생, 포인트, 상점과 운영 정책 관리 |
| 학부모 | 아이가 포인트를 얻고 사용하는 과정 확인 |

## 처음 시작하는 순서

1. 주인공은 이름과 숫자 4자리 비밀번호로 로그인합니다.
2. 선생님은 출석부에서 담당 반의 출석·어묵·재량을 기록합니다.
3. 좋은 행동은 출석부의 `JoyGrow`에서 칭찬합니다.
4. 포인트와 EXP가 쌓이면 주인공의 성경 인물과 여정이 성장합니다.
5. 모은 포인트는 포인트 상점에서 사용합니다.

## 학부모님께

순위보다 이번 주에 어떤 좋은 행동을 했는지 물어봐 주세요. JoyGrow 포인트는 신앙의 크기를 재는 점수가 아닙니다.

> 학생 화면, 선생님 출석부, 관리자 화면은 로그인 방법과 보이는 메뉴가 서로 다릅니다.
