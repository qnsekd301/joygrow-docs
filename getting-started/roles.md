# 학생·교사·관리자의 차이

각 역할은 필요한 정보와 작업만 볼 수 있습니다.

| 역할 | 할 수 있는 일 |
|---|---|
| 학생 | 내 포인트·EXP·퀘스트·성경 이야기·상점·성장 기록 확인 |
| 담임 교사 | 담당 반 학생 확인, 출석과 성장 활동 기록, 칭찬 지급과 최근 지급 취소 |
| 칭찬 지원 교사 | 담당 부서 학생에게 챈트 완료 또는 선생님 도움 칭찬 지급 |
| 부서 관리자 | 담당 부서 범위의 학생과 JoyGrow 운영 정보 확인 |
| 총관리자 | 전체 학생, 포인트, 성장 기준, 상점, 이벤트, 기록 관리 |
