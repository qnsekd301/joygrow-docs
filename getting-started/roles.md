# 학생·선생님·관리자의 차이

로그인한 역할과 담당 범위에 따라 보이는 메뉴가 달라집니다.

| 역할 | 볼 수 있는 범위 | 주요 작업 |
|---|---|---|
| 주인공(학생) | 나의 기록 | 포인트·EXP·퀘스트·성경 인물·주문 확인 |
| 담임 선생님 | 담당 반 | 출석 기록, 학생 확인, 칭찬 지급과 최근 지급 취소 |
| 칭찬 지원 선생님 | 배정된 부서 | 허용된 학생과 칭찬 항목만 사용 |
| 부서 관리자 | 담당 부서 | 담당 부서 학생과 JoyGrow 운영 현황 확인 |
| 총관리자 | 1·2부 전체 | 통합 현황, 일괄 입력, 성장 항목과 이벤트 관리 |
| JoyGrow 독립 관리자 | 중앙 운영 범위 | 학생·포인트·상점·정책·믿음 원정대·감사 기록 관리 |

## 화면이 다르게 보인다면

1. 로그인한 이름이 맞는지 확인합니다.
2. 담당 부서와 반이 맞는지 확인합니다.
3. 필요한 메뉴가 계속 보이지 않으면 김환희 강도사에게 권한을 확인해 달라고 요청합니다.

> **기억하세요**  
> 메뉴가 없거나 버튼이 비활성화된 것은 대부분 오류가 아니라 역할·담당 범위·주간 한도에 따른 정상 동작입니다.
