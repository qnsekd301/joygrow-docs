# 포인트와 EXP

같은 활동을 기록해도 **포인트(P)**와 **EXP(경험치)**는 용도가 다릅니다.

| 구분 | 쓰는 곳 | 상품 주문 뒤 |
|---|---|---|
| 포인트 | 열매상점에서 선물 주문 | 사용한 만큼 잔액이 줄어듭니다. |
| EXP | 선택한 성경 인물과 믿음원정 성장 | 줄어들지 않습니다. |

## 어떻게 받나요?

선생님이 출석부에 예배 출석·어묵·재량을 기록하면 JoyGrow와 연결됩니다. 선생님이 직접 본 말씀·찬양·도움·전도 등의 활동은 출석부의 `JoyGrow` 화면에서 따로 칭찬합니다. 학생이 임의로 출석이나 선생님 칭찬을 입력하는 기능은 없습니다.

| 활동 | 현재 기본 포인트 | 기록하는 사람 |
|---|---:|---|
| 예배 출석 | 10P | 출석부 기록으로 연결 |
| 어묵 1~3회 / 4~6회 | 6P / 9P | 출석부 기록으로 연결 |
| 재량 | 2P | 담당 선생님 |
| 일반 칭찬 | 4P | 실제 행동을 확인한 선생님 |
| 암송·특별 활동·친구 전도 | 활동별로 다름 | 선생님 또는 관리자 확인 |

관리자가 활동 기준이나 특별 이벤트를 바꾸면 표시 금액이 달라질 수 있습니다. **실제 지급 버튼에 보이는 값이 최종 기준**입니다. 같은 칭찬을 무제한 받을 수는 없으며 주간·학생별 제한이 적용됩니다.

## 내역 확인하기

1. 로그인 직후 받은 포인트 알림이 나오면 활동명과 날짜를 읽습니다.
2. 화면 위 포인트를 눌러 최근 받은 내역을 다시 봅니다.
3. 전체 성장 흐름은 `보관함`의 기록을 확인합니다.
4. 보이지 않으면 한 번 새로고침한 뒤 선생님에게 **활동 날짜와 종류**를 알려 주세요. 저장 확인 전 같은 활동을 여러 번 요청하지 않습니다.

> 포인트는 믿음의 크기를 재는 점수가 아닙니다. 오늘 실제로 실천한 걸음을 기억하도록 돕는 기록입니다.
