# 포인트와 EXP

활동 하나를 기록하면 포인트와 EXP가 함께 쌓이지만, 쓰임과 숫자는 서로 다릅니다.

| 구분       | 쓰임                            |
| -------- | ----------------------------- |
| 포인트(P)   | 포인트 상점에서 상품 주문 또는 포인트데이 때 사용  |
| EXP(경험치) | 내가 고른 성경 인물과 여정 성장            |

## 활동별 적립 기준

**(출석부에서 출석, 어묵, 재량을 체크하면 JoyGrow에서 자동으로 포인트와 경험치가 올라갑니다)**

| 활동       |  포인트 | EXP | 기록 방법        |
| -------- | ---: | --: | ------------ |
| 예배 출석    |  10P |  30 | 출석부 자동       |
| 어묵 1\~3회 |   6P |  12 | 출석부 자동       |
| 어묵 4\~6회 |   9P |  18 | 출석부 자동       |
| 선생님 재량   |   3P |  10 | 출석부 자동       |
| 챈트       |  20P |  20 | 선생님 확인       |
| 말씀 집중    |   5P |  15 | 선생님 확인       |
| 찬양 열심히   |   5P |  15 | 선생님 확인       |
| 친구 도움    |   5P |  15 | 선생님 확인       |
| 선생님 도움   |   5P |  15 | 선생님 확인       |
| 친구 전도    | 100P |  50 | 등록과 실제 출석 확인 |
|          |      |     |              |

![포인트와 EXP가 보이는 홈](../.gitbook/assets/home.png)

> 상품을 주문하면 포인트만 차감됩니다. EXP와 이미 쌓인 성장 기록은 별도로 유지됩니다.
