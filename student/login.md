# 로그인

이름을 검색해 나를 고른 뒤 숫자 4자리 비밀번호로 들어갑니다.

![주인공 로그인 화면](../images/student/login.png)

## 이 화면에서 할 수 있어요

① 이름 검색  
② 부서와 반 확인  
③ 숫자 4자리 비밀번호 입력

## 이렇게 사용하세요

1. 이름을 띄어쓰기 없이 정확하게 입력합니다.
2. 검색 결과에서 내 **부서와 반**을 확인합니다.
3. 내 이름을 누릅니다.
4. 비밀번호 숫자 4자리를 입력하고 `로그인`을 누릅니다.

## 문제가 있나요?

- 이름이 없으면 담당 선생님에게 등록 상태를 확인해 달라고 합니다.
- 같은 이름이 여러 명이면 부서와 반으로 구분합니다.
- 비밀번호를 잊었으면 추측을 반복하지 말고 담당 선생님이나 김환희 강도사에게 말합니다.

> **기억하세요**  
> 다른 사람의 이름을 고르거나 비밀번호를 친구에게 알려 주면 안 됩니다.
