# 열매상점과 주문

학생 화면의 `상점` 메뉴가 **열매상점**입니다. 포인트로 선물을 주문할 수 있습니다.

![열매상점](../images/student/store.png)

## 먼저 목표 정하기

원하는 상품의 **목표로 정하기**를 누르면 필요한 포인트와 현재 진행 정도를 볼 수 있습니다. 목표를 정하는 것만으로 포인트가 빠지지는 않습니다.

## 실제 주문하기

1. `상점`에서 상품 사진·설명·필요 포인트·품절 여부를 확인합니다. 사진이 여러 장이면 넘겨서 볼 수 있습니다.
2. 포인트가 충분하고 재고가 있으면 **구매하기**를 누릅니다.
3. 확인 창의 **현재 포인트 / 구매 후 포인트**를 읽습니다.
4. 맞으면 **○○P로 구매**를 한 번 누릅니다. 포인트가 바로 차감되고 주문이 관리자에게 전달됩니다.
5. 화면 아래 **내 주문 내역**을 열어 접수 상태를 확인합니다.

![구매 확인 창](../images/student/store-purchase-dialog.png)

| 주문 상태 | 뜻 |
|---|---|
| 준비 중 | 주문 접수. 아직 상품을 받기 전입니다. |
| 수령 완료 | 실제 상품을 받았고 관리자가 완료했습니다. |
| 취소됨 | 주문 취소가 처리된 상태입니다. 포인트 반영을 확인하세요. |

구매 후 응답이 늦어도 버튼을 연달아 누르지 말고 **내 주문 내역**을 먼저 확인하세요. 상품을 받는 방법은 담당 선생님이나 관리자에게 문의합니다.
