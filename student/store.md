# 열매상점

모은 포인트로 원하는 상품을 고르고 목표를 세우는 화면입니다.

![학생 열매상점 화면](../images/student/store.png)

## 이 화면에서 할 수 있어요

① 현재 포인트와 상품 가격 확인  
② 갖고 싶은 상품을 목표로 정하기  
③ 상품 주문과 이전 주문 확인

## 이렇게 사용하세요

1. 홈에서 `열매상점 보기`를 누릅니다.
2. 상품의 가격과 재고를 확인합니다.
3. 원하는 상품의 주문 버튼을 누릅니다.

![상품 구매 확인 창](../images/student/store-purchase-dialog.png)

> 기억하세요  
> 주문 상태와 실제 수령 방법은 담당 선생님에게 확인하세요.
