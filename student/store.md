# 포인트 상점

모은 포인트로 원하는 상품을 목표로 정하고 주문합니다. 현재 앱 화면에는 `열매상점`이라고 표시될 수 있습니다.

![포인트 상점 화면](../images/student/store.png)

## 이 화면에서 할 수 있어요

① 현재 포인트와 상품 가격 확인  
② 원하는 상품을 목표로 설정  
③ 재고를 확인하고 상품 주문  
④ 주문 상태와 이전 주문 확인

## 이렇게 주문하세요

1. 홈의 `열매상점 보기`를 누릅니다.
2. 가격과 재고, 내 포인트를 확인합니다.
3. 원하는 상품의 구매 버튼을 누릅니다.
4. 확인 창에서 상품과 사용할 포인트를 다시 확인합니다.

![상품 구매 확인 창](../images/student/store-purchase-dialog.png)

## 주문 뒤에는

- 주문과 동시에 포인트와 재고가 반영됩니다.
- `준비 중`이면 관리자가 상품을 준비하고 있습니다.
- 상품을 받은 뒤 관리자가 `수령 완료`로 바꿉니다.
- 대기 중인 주문이 취소되면 사용한 포인트가 환불됩니다.

> **기억하세요**  
> 같은 버튼을 여러 번 누르지 말고, 주문 내역에서 상태를 먼저 확인하세요.
