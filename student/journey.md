# 퀘스트·세계·랭킹·보관함

학생 화면 아래에는 여섯 메뉴가 있습니다. `홈`에서 시작해 `퀘스트 → 세계 → 랭킹 → 상점 → 보관함`을 필요할 때 열어 보세요.

## 퀘스트: 이번 주 할 일

![퀘스트 화면](../images/student/quests.png)

1. `퀘스트`에서 이번 주 진행 중인 활동과 완료 조건을 읽습니다.
2. 출석부 기록이나 선생님의 칭찬으로 진행되는 항목은 실제 기록이 반영될 때 상태가 바뀝니다.
3. `EXP 받기`가 나타난 완료 퀘스트는 버튼을 눌러 보상을 받습니다.
4. 더 해 보고 싶다면 화면의 자유 미션과 성장 상자를 확인합니다.

학생이 선생님의 관찰 기록을 직접 완료 처리하거나 선생님에게 앱으로 일반 퀘스트 승인을 요청하는 방식은 아닙니다.

## 세계: 성경 이야기와 믿음원정

![세계 화면](../images/student/world.png)

`세계`에서 선택한 성경 인물의 이야기 장면을 읽고, **장면 → 선택 → 실천** 순서로 따라갑니다. 열리지 않은 이야기는 안내된 성장 조건을 먼저 확인합니다. 아래로 내려가면 이야기 지도, 지역, 성경 탐험 퍼즐과 시대 도감을 볼 수 있습니다. 화면이 작으면 일부 내용이 접혀 있으므로 제목을 눌러 펼치세요.

## 랭킹: 순서 읽기

![랭킹 화면](../images/student/ranking.png)

반 대항, EXP, 출석왕, 어묵왕 등 서로 다른 기준을 따로 봅니다. 각 랭킹의 **높은 순/낮은 순** 버튼을 누르면 표시 순서가 바뀝니다. 랭킹은 참여 기록을 보는 참고 자료이며 누구의 믿음이 더 좋은지 평가하지 않습니다.

## 보관함: 지난 성장 보기

`보관함`에서 얻은 아이템과 아직 잠긴 아이템을 확인합니다. 얻은 아이템은 장착할 수 있습니다. 업적·칭호·출석·어묵·성장 기록도 이곳에서 다시 봅니다. 모바일에서는 **업적과 성장 기록**처럼 접힌 영역을 눌러 펼쳐야 할 수 있습니다.

> 인물을 바꾸고 싶다면 아이템이나 기록을 지우지 말고 [설정에서 변경 요청](settings-and-records.md)을 하세요.
