# 성장과 퀘스트

이번 주에 도전할 예배·말씀·사랑·섬김 활동과 완료 상태를 확인합니다.

![주인공 퀘스트 화면](../images/student/quests.png)

![PC에서 본 퀘스트 상세](../images/student/desktop-quests.png)

## 이 화면에서 할 수 있어요

① 주간 퀘스트의 진행 상태 확인  
② 완료된 퀘스트와 보상 확인  
③ 자유 미션과 주간 보물 확인

## 어떻게 완료되나요?

- 예배 출석과 어묵은 출석부 기록이 연결되면 반영됩니다.
- 챈트와 칭찬은 선생님이 실제 행동을 확인해 기록하면 반영됩니다.
- 친구 전도는 초대한 친구의 새가족 등록과 실제 예배 출석을 확인한 뒤 반영됩니다.

## 반영되지 않았나요?

1. 화면을 새로고침합니다.
2. 담당 선생님에게 활동이 기록되었는지 확인합니다.
3. 그래도 보이지 않으면 활동 이름과 날짜를 김환희 강도사에게 알려 주세요.

> **기억하세요**  
> 주인공이 직접 완료했다고 누르는 방식이 아니라, 출석부와 선생님의 확인 기록으로 완료됩니다.
