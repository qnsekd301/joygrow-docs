# 주인공 시작하기

JoyGrow에서 학생은 자기 성장 이야기의 **주인공**입니다. 홈에서 포인트와 성경 인물을 보고, 아래 탭에서 퀘스트와 믿음 원정대를 찾아갈 수 있습니다.

![주인공 홈 화면](../images/student/home.png)

## 먼저 알아둘 세 가지

① **포인트(P)**는 포인트 상점에서 사용합니다.  
② **EXP**는 내가 고른 성경 인물을 성장시킵니다.  
③ 출석과 좋은 행동을 선생님이 확인하면 두 기록이 함께 쌓입니다.

## 아래 메뉴

| 메뉴 | 하는 일 |
|---|---|
| 홈 | 오늘의 걸음, 포인트, 성경 인물 확인 |
| 퀘스트 | 이번 주 활동과 완료 상태 확인 |
| 세계 | 성경 이야기와 믿음 원정대 확인 |
| 랭킹 | 나와 공동체의 꾸준한 성장 확인 |
| 보관함 | 아이템·칭호·업적·지난 기록 확인 |

> **기억하세요**  
> 포인트를 많이 모으는 것보다 예배와 말씀, 섬김을 꾸준히 이어 가는 것이 더 중요합니다.
