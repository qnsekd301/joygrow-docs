# 학생 로그인과 홈

JoyGrow에서 학생은 이야기의 주인공입니다. [학생 로그인 화면](https://songrim-point.netlify.app/student/login)을 열어 시작하세요.

![JoyGrow 학생 로그인 화면](../images/student/login.png)

## 처음 로그인하기

1. 검색창에 내 이름을 입력하고 **검색**을 누릅니다. 입력 중에도 결과가 나타날 수 있습니다.
2. 결과에서 **1부·2부와 반**이 모두 맞는 내 이름을 선택합니다. 같은 이름의 다른 친구를 누르지 않도록 확인하세요.
3. 숫자 **4자리 비밀번호**를 입력합니다.
4. 처음 사용하는 비밀번호라면 화면 안내에 따라 새 4자리로 바꿉니다. 비밀번호는 친구와 공유하지 않습니다.

이름이 없거나 비밀번호를 잊었다면 여러 번 추측하지 말고 선생님에게 알려 주세요. 계정 정보는 관리자가 확인합니다.

## 홈에서 무엇을 보나요?

![JoyGrow 학생 홈](../images/student/home.png)

| 화면 | 볼 것 | 다음 행동 |
|---|---|---|
| 화면 위 포인트 | 지금 사용할 수 있는 포인트와 최근 받은 내역 | 숫자가 달라 보이면 받은 포인트 알림을 확인 |
| 오늘 한 걸음 | 이번 주에 이어갈 말씀과 행동 | 안내된 이야기나 퀘스트로 이동 |
| 성경 인물 | 선택한 인물, 레벨, EXP | 처음이라면 인물을 선택 |
| 하단 메뉴 | 홈·퀘스트·세계·랭킹·상점·보관함 | 보고 싶은 영역을 선택 |

로그인하면 새로 받은 포인트가 있을 때 **무엇으로 몇 포인트를 받았는지** 알림이 나타납니다. 확인을 누르면 닫히며, 화면 위 포인트 영역에서 최근 내역을 다시 볼 수 있습니다. 출석·어묵·선생님 칭찬 등 지급 이유를 구분해 보여 줍니다.

## 첫 성경 인물 선택

처음 들어갔을 때 인물 선택 화면이 나타나면 설명을 읽고 한 명을 고릅니다. 인물은 내가 따라 걷는 성경 이야기의 동행자입니다. 선택한 뒤 바꾸고 싶다면 [설정에서 변경 요청](settings-and-records.md)을 보냅니다. 포인트와 EXP는 서로 다른 기록입니다.

> 공용 기기에서는 사용 후 오른쪽 위 **설정 → 로그아웃**을 누르세요.
