# 홈·공지·월간계획

선생님 홈에는 이번 주에 필요한 공지와 월간 사역계획, 우리 반 출석 현황이 함께 나타납니다. **공지와 월간계획은 홈에서만 보이고**, 다른 메뉴로 이동하면 상단에 계속 고정되지 않습니다.

## 공지 확인하기

1. 홈의 `공지사항`에서 제목을 눌러 본문·사진·링크·게시 날짜를 읽습니다.
2. 바로 답할 수 없다면 **나중에 다시 보기**를 누릅니다. 미확인 상태는 남습니다.
3. 확인 응답이 필요한 공지는 다 읽은 뒤 **확인했어요**를 누릅니다. 일반 공지는 **읽고 닫기**가 표시됩니다.
4. 수정되어 다시 게시된 공지는 내용이 달라졌는지 확인하고 다시 응답합니다.

공지의 `9월 1주차` 같은 표기는 현재 날짜에 맞춰 바뀝니다. 지난 공지를 볼 때는 본문의 실제 게시 날짜와 적용 기간을 함께 확인하세요.

## 월간 사역계획 읽기

1. 홈의 **월간 사역계획 → 계획 보기**를 누릅니다.
2. 기간과 제목을 확인하고 **말씀계획**부터 읽습니다. 말씀 본문·설교 방향, 주차별 예배 내용이 이어집니다.
3. 각 주의 **2부순서**는 별도 영역에 더 크게 표시됩니다. 해당 주의 활동과 비고를 확인합니다.
4. 어묵본문과 어묵 날짜가 적힌 주는 주차 날짜 옆의 작은 날짜도 확인합니다.
5. **이번 주로**를 누르면 해당 주차로 이동합니다. 필요하면 **복사**로 계획 내용을 공유합니다.
6. 끝까지 읽은 뒤 **계획 확인했어요**를 누릅니다. 게시된 계획이 수정되면 다시 확인해야 합니다.

주차 표시는 입력된 예배 날짜를 기준으로 계산됩니다. 특정 주차의 날짜가 이상하면 임의로 해석하지 말고 관리자에게 알려 주세요.

## 오늘 할 일

홈의 **출석 미체크**를 누르면 아직 출결을 정하지 않은 학생만 볼 수 있습니다. **결석 사유**를 누르면 사유가 빠진 학생을 확인합니다. 숫자를 없애기 위해 추측으로 결석 처리하거나 사유를 만들지 않습니다.
