# JoyGrow 칭찬과 포인트 기준

담당 반 선생님은 출석부 하단 **JoyGrow**에서 학생의 실제 행동을 선택해 칭찬합니다. 출석·어묵·재량은 출석부에 기록한 내용이 연결되므로 여기서 다시 지급하지 않습니다.

![JoyGrow 칭찬 화면](../images/teacher/joygrow.png)

## 기본 지급 기준

| 구분 | 활동 | 현재 기본 포인트 | 기록 위치 |
|---|---|---:|---|
| 연결 | 예배 출석 | 10P | 출석부 `출석` |
| 연결 | 어묵 1~3회 / 4~6회 | 6P / 9P | 출석부 `출석` |
| 연결 | 재량 | 2P | 출석부 `출석` |
| 직접 칭찬 | 말씀 집중·찬양·친구 도움·선생님 도움 등 일반 칭찬 | 4P | 출석부 `JoyGrow` |
| 특별 확인 | 암송·챈트·친구 전도 등 | 항목별 화면 표시값 | 출석부 `JoyGrow` |

EXP는 활동별로 따로 쌓입니다. 관리자 설정이나 기간 한정 이벤트가 있다면 값이 바뀔 수 있으므로 **버튼에 표시된 포인트가 최종 기준**입니다.

## 한 명 칭찬하기

1. 학생 이름과 반을 확인합니다.
2. 실제로 본 행동에 맞는 칭찬 버튼을 누릅니다. 특별 항목의 확인 창이 나타나면 조건을 다시 읽습니다.
3. 지급 완료 메시지와 학생 카드의 `이번 주 칭찬` 상태를 확인합니다.
4. 잘못 눌렀다면 **오늘 준 포인트 → 취소**에서 해당 기록을 확인하고 되돌립니다. 새 지급으로 숫자를 맞추지 않습니다.

## 주간 제한

일반 칭찬은 학생별 주간 횟수와 반별 항목 인원 제한이 있습니다. 기본적으로 학생 1명에게 일반 칭찬은 **주 2회**, 같은 항목은 **주 1회**, 한 항목의 반별 대상은 **반 인원의 30%를 올림한 수**까지입니다. 버튼의 `이번 주 완료`, `오늘 3명 완료` 같은 문구가 현재 적용된 제한을 알려 줍니다. 제한이 찼다고 다른 항목을 실제와 다르게 선택하지 않습니다.

반을 맡지 않는 선생님은 별도로 [주일 하루 최대 서로 다른 학생 3명](support-teacher.md)까지 칭찬할 수 있습니다.
