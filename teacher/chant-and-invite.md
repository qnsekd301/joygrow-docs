# 챈트와 친구 전도

월별 챈트 완료와 실제 친구 전도를 확인한 뒤 기록하는 특별 항목입니다.

![챈트와 친구 전도 버튼](../images/teacher/joygrow.png)

## 기준

| 항목 | 완료 기준 | 보상 | 제한 |
|---|---|---:|---|
| 챈트 | 그달 챈트를 노래하거나 말로 외워 담임 선생님께 확인받음 | 20P + 20 EXP | 학생별 주 1회 |
| 친구 전도 | 초대한 친구의 새가족 등록과 실제 주일예배 출석을 확인함 | 100P + 50 EXP | 학생별 주 1회 |

## 이렇게 기록하세요

1. 학생과 완료 사실을 직접 확인합니다.
2. `챈트` 또는 `친구 전도`를 누릅니다.
3. 재확인 창의 학생 이름과 항목을 다시 읽습니다.
4. 맞으면 확인을 눌러 반영합니다.

> **기억하세요**  
> 보상이 큰 항목이라 재확인 창이 표시됩니다. 친구를 초대했다는 말만으로 지급하지 않고 등록과 실제 출석까지 확인합니다.
