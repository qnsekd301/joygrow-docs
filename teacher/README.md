# 선생님 사용법

선생님은 출석부 안에서 출석과 JoyGrow 칭찬을 함께 기록합니다.

![선생님 홈](<../.gitbook/assets/home (1).png>)

## 주일에 이 순서로 하세요

1. 출석부에 이름과 숫자 4자리 비밀번호로 로그인합니다.
2. 하단 `출석`에서 담당 반의 출석·어묵·재량을 기록합니다.
3. 예배와 반 모임에서 좋은 행동을 발견합니다.
4. 하단 `JoyGrow`에서 학생과 칭찬 항목을 누릅니다.
5. 지급 완료 문구와 최근 기록을 확인합니다.

![출석 기록 화면](../.gitbook/assets/attendance.png)

## 메뉴 한눈에 보기

| 메뉴      | 하는 일                 |
| ------- | -------------------- |
| 홈       | 오늘 할 일과 담당 반 상태 확인   |
| 출석      | 출석·어묵·재량과 성장 포인트 기록  |
| JoyGrow | 학생별 칭찬, 챈트와 친구 전도 기록 |
| 통계      | 담당 반의 출석 흐름 확인       |
| 심방요청    | 돌봄이 필요한 상황 전달        |

## 메뉴가 보이지 않을 때

로그인한 이름, 담당 부서와 반을 확인합니다. 역할에 따라 학생 범위와 버튼이 다르며, 승인 대기 중이면 관리자의 승인이 필요합니다.

> 학생이 점수를 요구해서 주는 것이 아니라, 선생님이 직접 확인한 행동을 말로 칭찬한 뒤 기록합니다.
