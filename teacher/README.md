# 선생님 시작하기

선생님은 [송림소년부 출석부](https://songrim-attendance.netlify.app)에 로그인합니다. JoyGrow 학생 앱에서 교사 업무를 처리하지 않습니다.

![선생님 홈](../images/teacher/home.png)

## 주일에 하는 일

1. 출석부에 발급받은 계정으로 로그인하고 화면 위 **부서·반**이 맞는지 확인합니다.
2. `홈`의 [공지·월간계획](home-and-notices.md)을 읽고 필요한 항목은 확인 응답을 남깁니다.
3. `출석`에서 **이번 주 날짜**를 확인한 뒤 출석·결석·어묵·재량을 기록합니다.
4. 미체크와 결석 사유 누락이 없는지 확인합니다.
5. `JoyGrow`에서 직접 확인한 행동을 [칭찬](point-policy.md)합니다.
6. `통계`로 담당 반 흐름을 보고 돌봄이 필요하면 `심방요청`을 남깁니다.

## 하단 메뉴

| 메뉴 | 할 일 |
|---|---|
| 홈 | 오늘 할 일, 공지, 월간 사역계획 확인 |
| 출석 | 담당 반 출결·어묵·재량·결석 사유 기록 |
| JoyGrow | 담당 반 학생의 성장 활동 칭찬과 오늘 지급 취소 |
| 통계 | 담당 반의 출석 흐름 확인 |
| 심방요청 | 학생 돌봄·심방이 필요할 때 관리자에게 요청 |

오른쪽 위의 열쇠 모양은 **계정 설정**, 나가기 모양은 **로그아웃**입니다. 휴대폰을 다른 사람과 공유한다면 업무 후 로그아웃하세요.

## 화면이 다를 때

담당 반이 배정되지 않으면 출석을 입력할 수 없습니다. 계정 승인 대기나 담당 반 오류는 총관리자에게 요청하세요. 반을 맡지 않는 선생님은 [칭찬 지원 전용 화면](support-teacher.md)이 나타납니다.

> 출석 사실과 칭찬은 실제로 확인한 내용만 기록합니다. 저장이 끝나기 전에는 탭을 급하게 바꾸거나 같은 버튼을 연달아 누르지 마세요.
