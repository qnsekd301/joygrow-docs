# 학생 확인

담당 학생을 찾고 현재 포인트와 이번 주 칭찬 상태를 확인합니다.

![담당 학생 JoyGrow 화면](../images/teacher/joygrow.png)

## 이 화면에서 할 수 있어요

① 담당 반 학생 목록 확인  
② 이름으로 학생 검색  
③ 현재 포인트와 이번 주 칭찬 수 확인  
④ 학생별로 사용할 수 있는 활동 버튼 확인

## 이렇게 사용하세요

1. 하단 메뉴에서 `JoyGrow`를 누릅니다.
2. 이름 또는 학생 카드를 찾습니다.
3. 같은 이름이 있다면 부서와 반을 다시 확인합니다.
4. 학생 카드에 표시된 포인트와 버튼 상태를 확인합니다.

> **기억하세요**  
> 담임 선생님에게는 담당 반이, 칭찬 지원 선생님에게는 배정된 부서와 허용 항목이 표시됩니다.
