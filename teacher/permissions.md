# 권한과 승인

역할에 따라 보이는 학생과 사용할 수 있는 기능이 자동으로 제한됩니다.

![칭찬 지원 선생님 화면](../images/teacher/support-praise.png)

## 역할별 범위

- **담임 선생님**: 담당 반 출석과 학생별 JoyGrow 칭찬을 기록합니다.
- **칭찬 지원 선생님**: 배정된 부서에서 화면에 허용된 학생과 항목만 기록합니다.
- **부서 관리자**: 담당 부서 범위의 현황과 학생을 확인합니다.
- **총관리자**: 1·2부 통합 현황과 관리 기능을 사용합니다.

![관리자 승인 대기 화면](../images/teacher/approval-pending.png)

## 승인 대기 또는 메뉴가 없을 때

1. 현재 로그인한 이름을 확인합니다.
2. 담당 부서와 반이 정확한지 확인합니다.
3. 승인 대기 화면이면 관리자의 승인을 기다립니다.
4. 업무에 필요한 메뉴가 계속 없으면 김환희 강도사에게 역할과 담당 범위를 알려 주세요.

> **기억하세요**  
> 과거의 학생 퀘스트 승인 요청 방식은 사용하지 않습니다. 현재는 출석부 자동 연결과 선생님의 직접 기록 방식입니다.
