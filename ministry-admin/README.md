# JoyGrow 교역자 운영 노트

JoyGrow를 학생용 포인트 앱이 아니라 송림소년부의 교육·운영 시스템으로 이해하기 위한 교역자용 노트입니다.

![JoyGrow 관제센터](../images/admin/control-center.png)

## 5분 브리핑

| 질문 | 답변 |
|---|---|
| 왜 운영하나요? | 실물 포인트의 분실과 계산 부담을 줄이고 좋은 행동을 즉시 격려하기 위해서입니다. |
| 무엇이 연결되나요? | 출석부의 출석·어묵·재량과 선생님의 칭찬이 JoyGrow 포인트·EXP로 이어집니다. |
| 학생은 무엇을 보나요? | 포인트, 퀘스트, 성경 인물, 믿음 원정대와 포인트 상점을 봅니다. |
| 선생님은 무엇을 하나요? | 출석을 기록하고 실제로 본 말씀·찬양·섬김 행동을 칭찬합니다. |
| 관리자는 무엇을 하나요? | 명단, 점수 정책, 상점, 이벤트, 기록과 예외 상황을 관리합니다. |

## 운영의 핵심

`현장 관찰 → 정확한 기록 → 즉시 보상 → 성장 경험 → 운영 점검`

JoyGrow는 아이를 통제하는 벌점 시스템이 아닙니다. 좋은 행동을 발견하고 설명하며 반복하도록 돕는 긍정 강화 도구입니다.

## 이 노트의 범위

- 교역자가 매주 확인해야 할 운영 흐름
- 포인트와 EXP 정책
- 선생님·학생·관리자 권한의 경계
- 출석부와 JoyGrow 연결 구조
- 상점·이벤트·성경 인물 운영
- 오류, 개인정보와 감사 대응

> 최종 운영 책임과 전체 포인트 조정은 김환희 강도사가 담당합니다.
