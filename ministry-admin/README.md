# 교역자 운영 안내

출석부와 JoyGrow를 함께 운영하는 교역자를 위한 안내입니다. 처음 사용하는 선생님이나 학생에게는 [전체 사용 설명서](../README.md)의 역할별 시작 페이지를 공유하세요.

![JoyGrow 관제센터](../images/admin/control-center.png)

## 5분 브리핑

| 질문 | 답변 |
|---|---|
| 왜 운영하나요? | 실물 포인트의 분실과 계산 부담을 줄이고 좋은 행동을 즉시 격려하기 위해서입니다. |
| 무엇이 연결되나요? | 출석부의 출석·어묵·재량과 선생님의 칭찬이 JoyGrow 포인트·EXP로 이어집니다. |
| 학생은 무엇을 보나요? | 포인트, 퀘스트, 성경 인물, 믿음원정과 열매상점을 봅니다. |
| 선생님은 무엇을 하나요? | 홈의 공지·월간계획을 확인하고 출석을 기록하며, 실제로 본 말씀·찬양·섬김 행동을 칭찬합니다. |
| 관리자는 무엇을 하나요? | 명단, 점수 정책, 상점, 이벤트, 기록과 예외 상황을 관리합니다. |

## 운영의 핵심

`현장 관찰 → 정확한 기록 → 즉시 보상 → 성장 경험 → 운영 점검`

JoyGrow는 아이를 통제하는 벌점 시스템이 아닙니다. 좋은 행동을 발견하고 설명하며 반복하도록 돕는 긍정 강화 도구입니다.

## 역할과 책임

| 역할 | 현장에서 책임질 일 | 하지 않는 일 |
|---|---|---|
| 담임 선생님 | 담당 반 출석과 직접 본 행동 기록 | 전체 포인트 임의 조정 |
| 칭찬 지원 선생님 | 배정된 범위에서 주일 하루 최대 3명의 서로 다른 학생에게 칭찬 기록 | 담당 범위 밖 학생 관리 |
| 부서 관리자 | 담당 부서 현황과 연결 오류 확인 | 근거 없는 일괄 수정 |
| 총관리자 | 1·2부 통합 점검, 정책·일괄 입력 관리 | AI 결과의 무검토 반영 |
| 운영 책임자 | 정책 결정, 예외 승인, 감사와 최종 확인 | 기록 없이 구두로만 변경 |

## 운영이 잘 되고 있다는 기준

- 선생님이 예배 후 짧은 시간 안에 기록을 마칠 수 있습니다.
- 학생은 무엇을 잘해서 포인트를 받았는지 설명할 수 있습니다.
- 특정 학생에게 칭찬이 계속 몰리지 않습니다.
- 포인트 오류가 생겨도 원본 기록과 감사 로그로 원인을 찾을 수 있습니다.
- 상품 주문과 실제 전달 상태가 서로 맞습니다.

## 이 안내의 범위

- 교역자가 매주 확인해야 할 운영 흐름
- 포인트와 EXP 정책
- 선생님·학생·관리자 권한의 경계
- 출석부와 JoyGrow 연결 구조
- 전체 공지와 월간 사역계획 게시·확인
- 상점·이벤트·성경 인물 운영
- 오류, 개인정보와 감사 대응

> 포인트와 권한을 크게 변경할 때는 해당 부서의 운영 책임자와 변경 근거를 먼저 확인합니다.
