# 주일 운영 흐름

교역자는 모든 버튼을 직접 누르기보다, 선생님이 정확하게 기록할 수 있는 환경을 만들고 예외 상황을 처리합니다.

## 주일 전

- 선생님 계정 승인과 담당 반을 확인합니다.
- 새 학생, 반 이동, 복귀 학생이 출석부와 JoyGrow에 연결됐는지 확인합니다.
- 진행 중인 이벤트와 포인트 기준을 선생님에게 공지합니다.
- 포인트 상점의 재고와 수령 대기 주문을 확인합니다.

### 주일 전 10분 점검

| 순서 | 확인 항목 | 완료 기준 |
|---|---|---|
| 1 | 계정과 담당 반 | 새 선생님과 반 이동이 반영됨 |
| 2 | 학생 명단 | 새 학생·복귀 학생이 검색됨 |
| 3 | 이벤트 | 기간과 보상이 공지 내용과 같음 |
| 4 | 상점 | 품절 상품과 수령 대기 주문을 확인함 |
| 5 | 공지 | 이번 주 특별 기준을 선생님에게 전달함 |

## 예배 중

![선생님 JoyGrow 화면](../images/teacher/joygrow.png)

- 담임 선생님은 출석·어묵·재량을 출석부에 기록합니다.
- 말씀 집중, 찬양 열심히, 친구 도움, 선생님 도움은 직접 본 행동만 기록합니다.
- 챈트와 친구 전도는 완료 조건을 다시 확인한 뒤 기록합니다.
- 교역자는 중복 지급, 과도한 편중과 연결 오류를 살핍니다.

## 예배 후

- 미체크 출석과 자동 연결 실패를 확인합니다.
- 선생님 지급 로그에서 비정상 중복과 취소 요청을 확인합니다.
- 상품을 전달한 주문은 수령 완료로 처리합니다.
- 끝난 이벤트는 비활성화합니다.
- 필요한 조정에는 이유를 남기고 감사 로그를 확인합니다.

### 예배 후 10분 점검

1. 미체크 출석과 결석 사유를 확인합니다.
2. 자동 연결 실패 또는 미일치 학생을 확인합니다.
3. 일반 칭찬이 특정 학생에게 몰리지 않았는지 봅니다.
4. 챈트와 친구 전도의 확인 근거를 점검합니다.
5. 수정한 기록은 학생 화면에서 한 번 더 확인합니다.

## 다음 주로 넘길 수 없는 일

- 학생이 다른 사람의 계정으로 연결된 경우
- 여러 학생의 포인트가 동시에 잘못 반영된 경우
- 주문은 없는데 포인트만 차감된 경우
- 권한이 없는 계정에서 관리자 기능이 보이는 경우
- 실제 학생 개인정보가 공개 화면에 노출된 경우

## 교역자가 선생님에게 설명할 한 문장

“아이에게 왜 칭찬하는지 먼저 말해 주고, 직접 본 행동과 같은 버튼을 한 번만 눌러 주세요.”

> 문제가 생기면 값을 바로 덮어쓰지 말고 출석, 지급, 주문의 원본 기록부터 확인합니다.
