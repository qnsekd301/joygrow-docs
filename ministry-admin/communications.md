# 전체 공지와 월간 사역계획

선생님이 매주 한곳에서 필요한 정보를 보게 하려면 **출석부 홈**에 공지와 월간 사역계획을 게시합니다. 두 내용은 홈에만 표시되고 다른 메뉴 위를 가리지 않습니다.

| 내용 | 적합한 용도 | 선생님 확인 |
|---|---|---|
| 공지 | 짧은 변경·준비물·일정 안내 | 필요하면 확인 응답 요청 |
| 월간 사역계획 | 여러 주의 말씀계획과 비중이 큰 2부순서 | 게시·수정 후 계획 확인 |

## 게시 전 체크

1. 전체 선생님에게 공유할 내용인지, 일부 대상만 필요한 내용인지 구분합니다.
2. 날짜·예배·주차를 확인합니다. 주차 표기는 예배 날짜를 기준으로 자동 계산됩니다.
3. 월간계획은 **말씀계획 → 2부순서** 순서로 읽히며, 어묵본문 주간의 어묵 날짜가 맞는지 확인합니다.
4. 모바일 미리보기를 보고 긴 제목·표·사진이 잘리지 않는지 확인합니다.
5. 게시 후 선생님 계정의 홈에서 실제 표시와 확인 응답 상태를 점검합니다.

기존 문서를 AI로 변환할 때는 화면의 **AI JSON 가져오기** 전용 프롬프트를 사용합니다. 가져오기는 초안 로드이며 자동 게시가 아닙니다. 저장 전에 사람이 날짜와 내용을 검토합니다.
