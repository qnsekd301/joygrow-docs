# 포인트와 칭찬 정책

포인트는 열매상점에서 쓰는 잔액이고, EXP는 성경 인물과 믿음원정을 성장시키는 경험치입니다. 한 활동이 기록되면 두 값이 함께 쌓입니다.

## 현재 적립 기준

| 구분 | 활동 | 포인트 | EXP | 기록 방식 |
|---|---|---:|---:|---|
| 자동 | 예배 출석 | 10P | 30 | 출석부 |
| 자동 | 어묵 1~3회 | 6P | 12 | 출석부 |
| 자동 | 어묵 4~6회 | 9P | 18 | 출석부 |
| 자동 | 재량 | 2P | 10 | 출석부 |
| 직접 | 챈트 | 20P | 20 | 선생님 확인 |
| 직접 | 말씀 집중 | 4P | 15 | 선생님 확인 |
| 직접 | 찬양 열심히 | 4P | 15 | 선생님 확인 |
| 직접 | 친구 도움 | 4P | 15 | 선생님 확인 |
| 직접 | 선생님 도움 | 4P | 15 | 선생님 확인 |
| 직접 | 친구 전도 | 100P | 50 | 등록과 실제 출석 확인 |

## 일반 칭찬 제한

말씀 집중, 찬양 열심히, 친구 도움, 선생님 도움에 적용됩니다.

- 학생 1명당 네 항목을 합쳐 주 2개까지
- 같은 항목은 반 정원의 30%를 올림한 인원까지
- 같은 학생에게 같은 항목은 주 1회

이 제한은 몇 명에게만 칭찬이 몰리는 것을 줄이고, 선생님이 다양한 학생의 작은 변화를 발견하도록 돕습니다.

담임 반 출석을 맡지 않는 **칭찬 지원 선생님**은 별도로 **주일 하루 최대 3명의 서로 다른 학생**에게만 칭찬할 수 있습니다. 화면에 표시된 남은 인원을 확인하세요.

## 화면 문구 해석

| 표시 | 뜻 | 선생님 행동 |
|---|---|---|
| `2명 남음` | 해당 칭찬을 줄 수 있는 반 인원이 남음 | 실제 행동을 확인한 학생에게 지급 |
| `이번 주 완료` | 같은 학생에게 같은 항목이 이미 지급됨 | 다시 누르지 않음 |
| `2개 완료` | 학생의 일반 칭찬 주간 한도 도달 | 다음 주 다른 성장을 관찰 |
| `반 3명 완료` | 해당 항목의 반별 인원 한도 도달 | 다른 항목을 억지로 대신 지급하지 않음 |

## 공정하게 운영하는 질문

주일 마감 전에 다음 세 가지를 확인합니다.

1. 늘 눈에 띄는 학생에게만 칭찬이 몰렸는가?
2. 조용한 섬김과 작은 변화도 발견했는가?
3. 실제 행동보다 포인트 요구에 끌려 지급한 기록이 있는가?

## 특별 항목의 확인 기준

| 항목 | 지급 전 확인 |
|---|---|
| 챈트 | 그달 챈트를 노래하거나 말로 외워 담임 선생님께 확인받았는가 |
| 친구 전도 | 초대한 친구의 새가족 등록과 실제 주일예배 출석이 확인됐는가 |

## 정책을 바꿀 때

1. 변경 목적과 시작일을 정합니다.
2. 학생·선생님 화면에 미치는 영향을 확인합니다.
3. 선생님에게 변경 내용을 먼저 공유합니다.
4. 적용 후 표본 학생의 포인트와 EXP를 확인합니다.
5. 운영 노트와 사용자 가이드의 기준표를 함께 갱신합니다.

> 화면에 표시되는 현재 보상과 제한이 최종 기준입니다.
