# 포인트 모으기

좋은 활동이 기록되면 포인트와 EXP가 함께 올라가요.

| 이름 | 어디에 쓰나요? |
|---|---|
| 포인트(P) | 열매상점에서 원하는 상품을 살 때 사용해요. |
| EXP(경험치) | 내가 고른 성경 인물을 성장시켜요. |

## 이렇게 모을 수 있어요

| 활동 | 포인트 |
|---|---:|
| 예배 출석 | 10P |
| 어묵 1~3회 | 6P |
| 어묵 4~6회 | 9P |
| 선생님 재량 칭찬 | 2P |
| 말씀 집중 | 4P |
| 찬양 열심히 | 4P |
| 친구 도움 | 4P |
| 선생님 도움 | 4P |
| 챈트 | 20P |
| 친구 전도 | 100P |

![포인트와 성장이 보이는 홈](../.gitbook/assets/home.png)

## 누가 기록하나요?

- 출석, 어묵, 재량은 선생님이 출석부에 기록하면 자동으로 올라가요.
- 말씀 집중, 찬양, 도움, 챈트와 친구 전도는 선생님이 직접 확인한 뒤 기록해요.
- 내가 직접 완료 버튼을 누르는 방식은 아니에요.

## 바로 보이지 않나요?

1. 화면을 한 번 새로고침해요.
2. 그래도 없으면 담당 선생님께 물어봐요.
3. 어떤 활동을 언제 했는지 함께 말해 주세요.

> 같은 행동을 해도 매주 받을 수 있는 횟수가 정해져 있어요. 버튼이 완료로 보이면 다음 주의 새로운 성장을 기다려 주세요.

특별 이벤트의 보상은 다를 수 있어요. 그때는 화면에 표시된 포인트와 기간을 확인해 주세요. 아직 **일회용 QR 카드나 스크래치 코드 입력 기능은 없습니다.**
