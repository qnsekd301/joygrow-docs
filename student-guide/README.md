# JoyGrow 시작하기

JoyGrow에서는 여러분 한 명 한 명이 성장 이야기의 주인공이에요.

예배에 참여하고, 말씀을 듣고, 친구와 선생님을 도우면 포인트와 경험치를 받을 수 있어요.

휴대전화나 컴퓨터에서 [JoyGrow 열기](https://songrim-point.netlify.app/student/login)를 눌러 시작해요. 앱처럼 설치하고 싶다면 [접속·설치 안내](../getting-started/install.md)를 보세요. 설치하지 않아도 브라우저에서 바로 사용할 수 있어요.

![JoyGrow 로그인 화면](../.gitbook/assets/login.png)

## 로그인하는 방법

1. 내 이름을 검색해요.
2. 부서와 반이 맞는지 확인해요.
3. 내 이름을 눌러요.
4. 숫자 4자리 비밀번호를 입력해요.

같은 이름이 여러 명이면 부서와 반을 꼭 확인하세요.

![JoyGrow 홈 화면](../.gitbook/assets/home.png)

## 홈에서 가장 먼저 볼 것

| 어디를 볼까요? | 무엇을 알 수 있나요? |
|---|---|
| 화면 위 | 지금 사용할 수 있는 포인트 |
| 오늘 한 걸음 | 오늘의 안내와 이번 주 미션 |
| 성경 인물 카드 | 내 인물의 레벨과 경험치 |
| 화면 아래 | 홈, 퀘스트, 세계, 랭킹, 상점, 보관함 |

포인트를 받았다면 로그인할 때 **어떤 활동으로 받았는지** 알림이 뜰 수 있어요. 바로 닫아도 최근 활동은 나중에 다시 확인할 수 있어요.

## 꼭 기억해요

- 다른 친구의 이름으로 로그인하지 않아요.
- 비밀번호를 친구에게 알려 주지 않아요.
- 함께 쓰는 기기에서는 끝난 뒤 로그아웃해요.

> 포인트의 숫자보다 오늘 내가 한 좋은 행동이 더 중요해요.
