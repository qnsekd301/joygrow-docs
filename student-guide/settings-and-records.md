# 설정·비밀번호·내 기록

홈 오른쪽 위 **설정**을 누르면 내 계정을 관리할 수 있어요.

## 4자리 비밀번호 바꾸기

`설정 → 비밀번호 바꾸기`에서 새 숫자 4자리를 정해요. 처음 로그인할 때 변경 화면이 먼저 나올 수도 있어요. 비밀번호가 기억나지 않으면 선생님에게 본인 확인 후 초기화를 부탁하세요. 친구에게 번호를 알려 주지 않아요.

## 성경 인물 바꾸기

다른 성경 인물을 살펴보고 싶다면 **성경 인물 이야기 보기 · 변경 요청**을 열어요. 이미 고른 인물을 바꾸는 것은 바로 적용되지 않고 관리자가 확인해요. 승인 전에는 지금 인물로 계속 사용할 수 있어요.

## 포인트를 왜 받았는지 보기

로그인할 때 최근에 받은 포인트 안내가 뜰 수 있어요. 놓쳤다면 홈의 **현재 포인트 → 최근 받은 포인트 다시 보기** 또는 보관함의 활동 기록을 확인해요. 열매상점에서 포인트를 써도 이미 쌓인 EXP와 성장 기록은 사라지지 않아요.

기기를 같이 쓴다면 사용을 마친 뒤 **설정 → 로그아웃**을 눌러 주세요.
