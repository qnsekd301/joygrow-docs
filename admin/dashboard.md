# 관리자 홈

활성 학생, 포인트, 출석과 운영 작업을 한눈에 확인하는 시작 화면입니다.

![관리자 대시보드](../images/admin/dashboard.png)

## 이 화면에서 확인할 것

① 활성 학생 수와 연결 상태  
② 포인트·출석·성장 현황  
③ 처리할 주문과 승인 요청  
④ 왼쪽 관리 메뉴와 현재 작업 위치

## 작업을 시작하기 전에

1. 로그인한 관리자 계정을 확인합니다.
2. 오늘 처리할 요청과 경고를 확인합니다.
3. 수정할 대상과 관련 메뉴로 이동합니다.
4. 저장 뒤 대시보드와 실제 학생 화면에서 결과를 확인합니다.

> **기억하세요**  
> 대시보드 숫자가 예상과 다르면 바로 값을 고치기보다 학생 기록, 지급 이력, 감사 로그를 먼저 확인하세요.
