# 감사 로그

관리자가 바꾼 학생, 포인트, 상품, 정책과 요청 처리 기록을 시간순으로 확인합니다.

![관리자 감사 로그](../images/admin/audit-log.png)

## 이런 때 확인하세요

- 학생 포인트가 예상과 다를 때
- 상품이나 재고 값이 바뀌었을 때
- 성경 인물 요청 처리 결과를 확인할 때
- 정책 또는 이벤트 변경의 담당자와 시간을 찾을 때
- 예상하지 못한 운영 변경이 발견됐을 때

## 확인 순서

1. 발생한 날짜와 작업 종류를 좁힙니다.
2. 변경한 관리자와 대상 기록을 확인합니다.
3. 변경 전·후 상세 내용을 펼칩니다.
4. 관련 학생 기록이나 주문 이력과 대조합니다.

> **기억하세요**  
> 감사 로그는 잘못을 찾기 위한 명단이 아니라, 운영 변경을 안전하게 추적하고 복구 판단을 돕는 기록입니다.
