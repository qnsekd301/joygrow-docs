# 학생·계정·포인트

학생의 이름·부서·반은 출석과 JoyGrow가 연결될 때 기준이 됩니다. 기존 학생을 다시 추가하기 전에 반드시 검색하세요.

## 학생 추가·수정

1. JoyGrow 관리자 `학생 관리` 또는 출석부 `학생`에서 이름을 검색합니다.
2. 같은 이름이 있으면 **부서·반**을 함께 확인합니다.
3. 학생 추가 또는 수정 화면에서 소속, 반, 필요한 기본 정보를 입력합니다.
4. 저장 후 출석부 명단과 JoyGrow 검색 결과가 같은 학생을 가리키는지 확인합니다.

학생의 반 이동·장결·삭제는 과거 출석과 목양 기록에 영향을 줄 수 있으므로 [학생과 반 관리](../attendance-admin/students-and-classes.md)를 먼저 읽으세요.

## 학생 비밀번호 초기화

JoyGrow 관리자 `학생 관리 → 해당 학생 수정`에서 비밀번호 초기화를 선택할 수 있습니다. **선택한 학생 한 명**의 이름·부서·반을 다시 확인한 뒤 실행합니다. 초기 비밀번호로 로그인한 학생에게는 새 4자리 비밀번호 설정을 안내합니다. 초기 비밀번호를 공개 채팅방에 올리지 않습니다.

## 포인트 직접 조정

1. `학생 관리`에서 대상 학생과 현재 잔액을 확인합니다.
2. 증감할 포인트와 분류, 알아볼 수 있는 지급·차감 이유를 입력합니다.
3. 반영 전후 포인트를 확인하고 저장합니다.
4. 학생 화면의 잔액과 관리자 이력을 다시 확인합니다.

교사의 잘못된 직접 지급이나 관리자의 일괄 지급은 원본 기록을 찾아 **취소**하는 편이 추적하기 쉽습니다. 한 번의 일괄 지급은 여러 학생을 포함한 **하나의 지급 사건**일 수 있으므로 전체 취소 전에 대상 명단과 합계를 펼쳐 확인하세요. 취소된 기록도 이력에서 확인할 수 있습니다.

## GPT로 여러 학생 지급

출석부 관리자 `전체 → JoyGrow`의 전용 기능입니다. 프롬프트를 복사하고 개인정보가 없는 활동 내용을 정리해 JSON을 붙여 넣습니다. **명단·점수 검사 → 동명이인·미일치·이상값 확인 → 잘못된 행 제외 → 최종 인원·합계 확인 → 실제 반영** 순서로 진행하세요. GPT 결과를 검토 없이 저장하지 않습니다.

> 학생 연락처, 상담 내용, 비밀번호, 보안키는 GPT 입력에 넣지 마세요.
