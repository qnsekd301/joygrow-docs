# 열매상점·주문

JoyGrow 관리자 `열매상점`은 상품 공개와 주문 처리를 함께 관리합니다. 학생이 주문하면 포인트가 차감되고 수령 대기 기록이 생깁니다.

## 상품 만들기·수정하기

1. [JoyGrow 관리자](https://songrim-point.netlify.app/admin/login)에 로그인해 **열매상점**을 엽니다.
2. 기존 상품을 수정하거나 **상품 추가**를 선택합니다.
3. 이름·설명·카테고리·필요 포인트·재고·정렬·공개 여부를 확인합니다.
4. 사진은 여러 장 선택해 올릴 수 있습니다. **첫 사진이 대표**이며 순서를 바꾸거나 다른 사진을 대표로 지정할 수 있습니다.
5. 업로드 중에는 저장을 반복하지 않습니다. 일부 사진만 실패하면 **실패한 사진만 다시 올리기**를 사용합니다.
6. 저장 후 학생 `상점`에서 사진 순서·가격·재고·품절 표시를 확인합니다.

공개 가능한 사진만 올리고 학생 얼굴이나 개인정보가 들어간 사진은 사용하지 않습니다. 상품을 지우거나 사진을 제거하기 전에는 기존 주문에 미치는 영향을 확인하세요.

## 주문 처리

1. 같은 화면의 **중앙 주문 관리**에서 `수령 대기` 건수를 확인합니다.
2. 주문한 학생·상품·날짜를 확인합니다.
3. 실제 상품을 건넨 뒤에만 **수령 완료**로 변경합니다.
4. 취소가 필요하면 주문 상태와 환불·재고 복구 결과를 확인합니다. 중복으로 수동 포인트를 더하지 않습니다.

학생에게는 `준비 중 → 수령 완료` 또는 `취소됨`으로 표시됩니다. 학생이 구매 성공 화면을 못 봤다고 해도 바로 재주문시키지 말고 **내 주문 내역**과 관리자 주문을 먼저 대조하세요.
