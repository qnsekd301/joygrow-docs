# 관제센터

학생 참여, 포인트 흐름, 인기 목표 상품과 공동체 목표를 운영 관점에서 살펴봅니다.

![JoyGrow 관제센터](../images/admin/control-center.png)

## 이 화면에서 할 수 있어요

① 참여와 포인트의 주요 지표 확인  
② 참여가 줄어든 학생 신호 확인  
③ 인기 목표 상품과 예상 달성 흐름 확인  
④ 공동체 목표 생성과 진행 상태 확인

## 숫자를 해석하는 순서

1. 기간과 대상 범위를 확인합니다.
2. 전체 숫자보다 갑자기 달라진 항목을 찾습니다.
3. 학생 개인 기록과 최근 지급·조정 내역을 확인합니다.
4. 필요한 경우 담당 선생님과 실제 상황을 확인합니다.

> **기억하세요**  
> 관제 신호는 돌봄을 위한 확인 출발점입니다. 숫자만으로 학생의 태도나 믿음을 판단하지 않습니다.
