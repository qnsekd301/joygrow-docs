# 출석부 JoyGrow 통제센터

출석부 관리자 화면에서 1·2부의 JoyGrow 운영 현황과 교사 지급 기록을 함께 관리합니다.

![출석부 JoyGrow 통제센터](../images/admin/attendance-control.png)

## 이 화면에서 할 수 있어요

① 운영비서 브리핑과 진행·종료 이벤트 확인  
② 반·EXP·출석·어묵 랭킹 확인  
③ 학생별 포인트 직접 조정  
④ 성장 항목과 특별 이벤트 빠른 설정  
⑤ 총관리자 지급 이력과 선생님 성장 지급 로그 확인

## GPT 포인트 일괄 입력

여러 학생의 활동을 한 번에 정리해야 할 때만 총관리자가 사용합니다.

1. 화면의 전용 프롬프트를 복사합니다.
2. 개인정보를 최소화한 활동 내용을 준비합니다.
3. GPT가 만든 JSON 결과를 입력 칸에 붙여넣습니다.
4. `검사`를 눌러 학생 매칭, 항목, 포인트와 경고를 확인합니다.
5. 동명이인·미일치·이상한 숫자는 제외하거나 수정합니다.
6. 최종 대상과 총액을 사람이 다시 확인한 뒤 반영합니다.

> **절대 붙여넣지 마세요**  
> 전화번호, 부모 연락처, 상담·목양 기록, 비밀번호, 관리자 인증정보와 내부 보안값은 GPT 입력에 넣지 않습니다.

## 기록 취소

총관리자 지급 묶음과 선생님 지급 로그에서 화면에 취소 버튼이 있는 기록만 취소할 수 있습니다. 이미 취소된 기록, 정책상 취소할 수 없는 기록은 버튼이 표시되지 않습니다.

> **기억하세요**  
> AI 결과는 초안입니다. 저장 책임은 최종 검토한 관리자에게 있습니다.
