# 공지·월간 사역계획 게시

두 기능 모두 출석부 **홈**에서 전체 선생님에게 공유합니다. 일반 공지는 짧은 전달 사항, 월간 사역계획은 여러 주의 말씀계획과 2부순서를 담는 문서입니다. 관리자에게 보이는 작성 버튼은 권한에 따라 다릅니다.

## 공지 게시

1. 출석부 홈의 **공지 작성**을 누릅니다.
2. 선생님이 바로 이해할 제목과 본문을 적습니다. `Enter`는 문단 간격, `Shift+Enter`는 붙은 줄바꿈입니다. 굵게·소제목·강조·링크·목록 버튼도 사용할 수 있습니다.
3. 사진을 첨부했다면 **사진 설명**을 쓰고, 순서·크기·사진 아래 글을 확인합니다. 기기에 임시저장된 글은 사진까지 보존하지 않을 수 있으므로 새로고침 전에 저장하세요.
4. **중요도·보낼 대상·게시 종료일**을 정합니다. 필요하면 **확인 응답 받기**와 **목록 위에 고정**을 켭니다.
5. **선생님 화면 미리보기**로 모바일 표시를 확인한 뒤 **지금 게시**를 누릅니다. 아직 공개하지 않으려면 **임시저장**을 사용합니다.
6. 게시 후 교사 홈에서 보이는지, 확인 응답이 필요한 공지는 누가 확인했는지 점검합니다.

수정된 공지를 **수정하고 다시 알림**으로 게시하면 선생님이 새 내용을 다시 확인하게 됩니다. `게시 종료`는 삭제가 아니라 현재 홈 목록에서 내리는 기능입니다. 공지의 주차 표기는 현재 날짜를 기준으로 자동 표시되므로 제목에 주차를 억지로 반복 입력할 필요는 없습니다.

## 월간 사역계획 게시

1. 홈의 **월간 사역계획 → 관리 → 새 계획**을 엽니다.
2. **계획 제목, 시작 달, 마지막 달, 이번 계획의 방향**을 입력합니다.
3. 주차를 추가하고 각 주의 **예배 날짜, 핵심본문, 말씀 후 찬양, 설교 주제**를 입력합니다. 어묵본문이 있는 주에는 함께 안내할 어묵 날짜를 정확히 적습니다.
4. 각 주의 **2부순서 활동, 진행 방법·비고, 준비물·특별 일정**을 별도 영역에 작성합니다.
5. **모바일 미리보기**에서 말씀계획이 먼저, 2부순서가 더 큰 별도 영역으로 읽히는지 확인합니다.
6. **임시저장** 또는 **전체 선생님께 게시**를 선택합니다. 임시저장은 선생님에게 보이지 않습니다.

주차명은 입력한 예배 날짜에서 자동 계산됩니다. 게시된 계획을 수정해 **변경 내용 다시 게시**하면 선생님의 확인 상태가 새 내용 기준으로 다시 필요해집니다.

## 기존 계획을 AI JSON으로 가져오기

기존 표나 문서가 있으면 **AI JSON 가져오기 → 전용 프롬프트 복사 → 변환 결과 붙여 넣기 → JSON 검토 → 편집기에 불러오기** 순서로 사용합니다. 이것은 바로 게시가 아닙니다. 가져온 뒤 날짜·빈 항목·주차 순서를 사람이 확인하고 모바일 미리보기를 본 다음 게시합니다. 학생 개인정보나 비밀번호는 변환 프롬프트에 넣지 않습니다.

> 공지와 월간계획을 게시한 뒤에는 반드시 **선생님 계정의 홈**에서 실제 표시를 확인하세요.
