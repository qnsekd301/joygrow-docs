# 관리자 주간 체크리스트

주일 운영 전후에 JoyGrow와 출석부 연결을 빠짐없이 확인합니다.

## 주일 전

- [ ] 활성 이벤트의 시작일·종료일 확인
- [ ] 포인트 상점 재고와 수령 대기 주문 확인
- [ ] 새 학생·반 이동·복귀 학생의 명단 연결 확인
- [ ] 선생님 계정 승인과 담당 반 확인

## 주일 후

- [ ] 출석·어묵·재량 자동 연결 오류 확인
- [ ] 미일치 학생과 동명이인 경고 확인
- [ ] 교사 지급 로그와 비정상 중복 확인
- [ ] 수령 완료 상품 처리
- [ ] 끝난 이벤트 비활성화 확인

## 문제가 발견되면

1. 값을 바로 덮어쓰지 말고 원본 출석·지급·주문 기록을 확인합니다.
2. 학생 이름과 부서·반, 발생 시각을 대조합니다.
3. 필요한 조정에는 알아볼 수 있는 사유를 남깁니다.
4. 처리 후 학생 화면과 감사 로그를 다시 확인합니다.
