# 성장 정책

출석과 성장 기회를 점수로 환산하는 중앙 정책을 관리합니다.

![관리자 성장 정책 화면](../images/admin/policy.png)

## 화면의 주요 값

- 시즌 전체 기회 수
- 점수 환산을 시작하는 최소 참여 횟수
- 최소 성장점수
- 현재 포인트 구간별 보정률
- 꾸준함 횟수별 보너스

## 안전하게 변경하세요

1. 변경 목적과 적용 날짜를 정합니다.
2. 현재 값과 바꿀 값을 따로 기록합니다.
3. 여러 참여 수준의 예상 결과를 비교합니다.
4. 저장 뒤 관제센터와 학생 기록을 표본 확인합니다.
5. 변경 사실을 선생님에게 공유합니다.

> **기억하세요**  
> 성장점수는 포인트 잔액과 다른 운영 지표입니다. 학생에게는 복잡한 계산식보다 꾸준한 참여를 응원하는 의미로 설명합니다.
