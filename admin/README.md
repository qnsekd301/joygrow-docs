# 관리자 시작하기

관리자는 목적에 따라 두 화면을 사용합니다. 계정 권한에 따라 메뉴와 수정 버튼이 다를 수 있습니다.

| 화면 | 들어가는 곳 | 주 업무 |
|---|---|---|
| 출석부 관리자 | [출석부](https://songrim-attendance.netlify.app) 로그인 | 1·2부 출석, 결석·목양, 주일보고, 공지·월간계획, 계정·반, JoyGrow 통제센터 |
| JoyGrow 관리자 | [JoyGrow 관리자 로그인](https://songrim-point.netlify.app/admin/login) | 학생·포인트, 관제센터, 성장 활동, 열매상점·주문, 믿음원정, 정책, 감사 로그 |

## 처음 확인할 순서

1. 로그인한 계정의 **역할·담당 부서**를 확인합니다. 읽기 전용 계정은 조회만 가능할 수 있습니다.
2. 출석부 홈에서 **미체크·결석 사유·공지·월간계획**을 확인합니다.
3. 담당 교사의 출석과 칭찬 기록이 JoyGrow에 연결됐는지 확인합니다.
4. 필요한 경우 [학생·포인트](students-and-points.md), [열매상점·주문](store-and-orders.md), [성장 활동·믿음원정](operations.md)을 처리합니다.
5. 마지막으로 주일보고와 돌봄 후속 조치를 마감합니다. 출석부 메뉴 전체는 [출석부 사용 가이드](../attendance-admin/README.md)에 정리했습니다.

## 권한의 차이

총관리자는 1·2부 통합 현황, 계정과 정책, 공지·월간계획 게시, 일괄 지급·취소를 관리합니다. 부서 관리자는 허용된 부서 범위에서 기록과 운영을 확인합니다. 읽기 전용 관리자는 저장·수정·삭제가 제한됩니다. 버튼이 없으면 우회하려 하지 말고 역할을 확인하세요.

## 수정 전 공통 확인

`대상 학생·부서·반 → 날짜 → 변경 내용 → 저장 후 결과` 순서로 확인합니다. 포인트를 바로 덮어쓰기 전에 원본 출석·교사 지급·주문 내역을 먼저 찾고, 되돌릴 때는 가능하면 해당 지급 사건의 취소 기능을 사용합니다.

> 출석부와 JoyGrow는 같은 학생을 연결해 사용합니다. 동명이인은 이름만으로 선택하지 마세요.
