# 포인트 상점 관리

상품, 가격, 재고와 학생 주문을 중앙에서 관리합니다. 현재 앱 화면에는 `열매상점`이라는 이름이 남아 있을 수 있습니다.

![관리자 포인트 상점](../images/admin/store.png)

## 상품 관리

1. 상품 이름과 설명을 짧고 분명하게 씁니다.
2. 포인트 가격과 재고를 입력합니다.
3. 외부 공개가 가능한 상품 이미지만 사용합니다.
4. 판매 여부를 확인하고 저장합니다.

## 주문 처리

| 상태 | 뜻 | 관리자 행동 |
|---|---|---|
| 수령 대기 | 주문과 포인트 차감이 완료됨 | 상품과 학생을 확인해 준비 |
| 수령 완료 | 학생에게 실제로 전달함 | 전달한 뒤에만 완료 처리 |
| 취소됨 | 대기 주문을 취소함 | 포인트 환불 여부 확인 |

## 취소와 환불

대기 중인 주문만 취소할 수 있습니다. 취소 처리 시 사용한 포인트는 환불되고 재고가 복원됩니다. 완료 주문은 화면에서 바로 취소할 수 없습니다.

> **기억하세요**  
> 선생님 화면에는 상점 관리 기능이 없습니다. 주문 처리는 JoyGrow 독립 관리자에서 합니다.
