# JoyGrow 공식 가이드

JoyGrow는 예배와 좋은 행동을 포인트와 성장 경험으로 이어 주는 송림소년부 시스템입니다.

![JoyGrow 주인공 홈](.gitbook/assets/home.png)

| ----------- | ---------------------------------- |
| 처음 보는 분·학부모 | [JoyGrow 한눈에 보기](getting-started/) |
| 주인공(학생)     | [주인공 사용법](student/)                |
| 선생님         | [선생님 사용법](teacher/)                |

## 한 줄로 이해하기

`출석과 좋은 행동 확인 → 포인트와 EXP 적립 → 성경 인물 성장 → 포인트 상점 이용`

> 포인트는 아이를 줄 세우는 점수가 아니라, 좋은 걸음을 발견하고 격려하는 도구입니다.

오류나 궁금한 점은 김환희 강도사에게 문의해 주세요. 비밀번호와 개인정보는 보내지 마세요.
