# 송림소년부 JoyGrow 공식 가이드

JoyGrow는 예배와 말씀 훈련, 칭찬을 **포인트와 성장 경험**으로 이어 주는 송림소년부의 디지털 성장 시스템입니다.

![JoyGrow 학생 홈](images/student/home.png)

## 누구신가요?

| 사용자 | 가장 먼저 볼 문서 | JoyGrow에서 하는 일 |
|---|---|---|
| 주인공(학생) | [학생 시작하기](student/README.md) | 내가 모은 포인트와 성장 여정 확인 |
| 선생님 | [선생님 5분 시작하기](teacher/README.md) | 출석을 기록하고 실제 행동을 칭찬 |
| 학부모 | [학부모 안내](getting-started/parents.md) | 아이가 포인트를 얻고 사용하는 과정 이해 |
| 관리자 | [관리자 시작하기](admin/README.md) | 학생·포인트·상점·정책과 기록 관리 |

## JoyGrow의 핵심 흐름

`출석과 활동 확인 → 포인트·EXP 적립 → 성경 인물 성장 → 포인트 상점 이용`

- **포인트(P)**: 포인트데이 상품을 주문할 때 사용하는 잔액입니다.
- **EXP(경험치)**: 주인공이 고른 성경 인물을 성장시키는 기록입니다.
- **선생님의 역할**: 결과보다 실제로 발견한 좋은 행동을 정확하게 기록합니다.

> **가장 중요한 원칙**  
> 포인트는 아이를 줄 세우기 위한 점수가 아니라, 예배와 말씀, 섬김의 좋은 걸음을 발견하고 격려하는 도구입니다.
