# 송림소년부 앱 사용 설명서

처음 사용하는 분도 이 설명서만 보고 출석부와 JoyGrow를 사용할 수 있도록 정리했습니다. 두 앱은 연결되어 있지만 사용하는 사람이 다릅니다.

| 내가 하려는 일 | 사용할 곳 | 먼저 읽을 페이지 |
|---|---|---|
| 우리 반 출석·결석을 기록하고 공지·월간계획을 확인하기 | [송림소년부 출석부](https://songrim-attendance.netlify.app) | [선생님 시작하기](teacher/README.md) |
| 내 포인트·퀘스트를 보고 열매상점을 이용하기 | [JoyGrow](https://songrim-point.netlify.app/student/login) | [학생 로그인과 홈](student/README.md) |
| 학생·포인트·상품·이벤트를 관리하기 | 출석부 또는 JoyGrow 관리자 화면 | [관리자 시작하기](admin/README.md) |
| 반을 맡지 않고 담당 부서 학생을 칭찬하기 | 출석부의 `칭찬` | [칭찬 지원 선생님](teacher/support-teacher.md) |
| 문제가 생겼을 때 원인 찾기 | 각 앱의 현재 화면 | [문제 해결](help/README.md) |

## 처음이라면 이 순서대로

1. [앱 접속·설치](getting-started/install.md)에서 본인에게 필요한 주소를 엽니다. 설치는 선택 사항입니다.
2. [역할별 시작 안내](getting-started/README.md)에서 내 계정의 범위를 확인합니다.
3. 왼쪽 목차에서 학생·선생님·관리자 중 자신의 역할을 선택합니다.
4. 실제 화면의 날짜, 부서, 반, 학생 이름을 확인한 뒤 기록합니다.
5. 저장 후에는 완료 표시나 내역을 확인합니다. 숫자가 예상과 다르면 [문제 해결](help/README.md)을 봅니다.

## 두 앱의 연결

`출석부에서 실제 출석·어묵·재량과 칭찬 기록 → JoyGrow 포인트·EXP와 학생 화면에 반영`

학생 화면은 결과를 보는 곳이고, 선생님·관리자 화면은 확인한 사실을 기록하는 곳입니다. 포인트를 맞추기 위해 출석 사실을 바꾸지 않습니다.

> 이 설명서는 2026년 9월 운영 화면을 기준으로 합니다. 지급 포인트나 주간 제한은 관리자가 바꿀 수 있으므로 실제 지급 직전에는 화면에 표시된 값을 최종 확인하세요. 카드용 QR·고유번호 등록 기능은 아직 운영 기능이 아니며 이 설명서의 사용 절차에 포함하지 않았습니다.
